Concurrency & Async

threads, processes, asyncio, tasks, I/O-bound vs CPU-bound mental models

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. I/O-bound vs CPU-bound

সহজ ভাষায়: Waiting for network/files is different from heavy computation. This distinction guides concurrency choices.

Example

import time
print("Start")
time.sleep(1)
print("Done")

Line-by-line explanation

import time
print("Start")
time.sleep(1)
print("Done")
কেন কাজ করছে?
sleep simulates waiting. Async approaches can overlap waiting work.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Async task

সহজ ভাষায়: async def defines a coroutine and await pauses it without blocking other tasks.

Example

import asyncio
async def task(name):
    await asyncio.sleep(1)
    print(name)
async def main():
    await asyncio.gather(task("A"),task("B"))
asyncio.run(main())

Line-by-line explanation

import asyncio
async def task(name):
await asyncio.sleep(1)
print(name)
async def main():
await asyncio.gather(task("A"),task("B"))
asyncio.run(main())
কেন কাজ করছে?
gather schedules both coroutines so their waiting periods overlap.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Threading concept

সহজ ভাষায়: Threads can be useful for I/O-bound work.

Example

from concurrent.futures import ThreadPoolExecutor
with ThreadPoolExecutor(max_workers=2) as ex:
    print(list(ex.map(lambda x:x*x,[1,2,3])))

Line-by-line explanation

from concurrent.futures import ThreadPoolExecutor
with ThreadPoolExecutor(max_workers=2) as ex:
print(list(ex.map(lambda x:x*x,[1,2,3])))
কেন কাজ করছে?
A pool manages worker threads for the submitted tasks.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Multiprocessing concept

সহজ ভাষায়: Separate processes can use multiple CPU cores for CPU-heavy work.

Example

from concurrent.futures import ProcessPoolExecutor
with ProcessPoolExecutor() as ex:
    print(list(ex.map(lambda x:x*x,[1,2,3])))

Line-by-line explanation

from concurrent.futures import ProcessPoolExecutor
with ProcessPoolExecutor() as ex:
print(list(ex.map(lambda x:x*x,[1,2,3])))
কেন কাজ করছে?
Processes have separate Python runtimes and are useful for CPU-bound workloads.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
