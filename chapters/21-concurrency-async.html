Concurrency & Async

threads, processes, asyncio, tasks, I/O-bound vs CPU-bound mental models

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. I/O-bound vs CPU-bound

সহজ ভাষায়: Waiting for network/files is different from heavy computation. This distinction guides concurrency choices.

Example

import time
print("Start")
time.sleep(1)
print("Done")

Line-by-line explanation

import timePython-এর বিল্ট-ইন time মডিউল লোড করা হয়েছে — সময় সম্পর্কিত ফাংশন (যেমন: sleep, timestamp) ব্যবহারের জন্য
print("Start")কনসোলে "Start" লেখা প্রিন্ট করে দেখানো হয়েছে — প্রোগ্রামটি কাজ শুরু করার সংকেত
time.sleep(1)পুরো program execution-কে ১ সেকেন্ডের জন্য সম্পূর্ণরূপে থামিয়ে (block করে) অপেক্ষা করানো হয়েছে — এটি I/O wait-এর simple simulation (network/API call প্রতিস্থাপন)
print("Done")১ সেকেন্ডের sleep শেষ হয়ে program আবার resume করার পর "Done" লেখা প্রিন্ট হয় — মোট সময় ~১ সেকেন্ড লেগেছে
কেন কাজ করছে?
sleep simulates waiting. Async approaches can overlap waiting work.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Async task

সহজ ভাষায়: async def defines a coroutine and await pauses it without blocking other tasks.

Example

import asyncio
async def task(name):
    await asyncio.sleep(1)
    print(name)
async def main():
    await asyncio.gather(task("A"),task("B"))
asyncio.run(main())

Line-by-line explanation

import asyncioPython-এর asyncio লাইব্রেরি লোড করা হয়েছে — async/await coroutine, event loop, task scheduling সব কিছু এই মডিউলেই থাকে
async def task(name):"task" নামে একটি async coroutine ফাংশন ডিফাইন করা হয়েছে যা name নামে parameter নেয় — async keyword দিয়ে চিহ্নিত ফাংশনগুলো সরাসরি run হয় না, বরং event loop-এ schedule হতে হয়
await asyncio.sleep(1)asyncio.sleep(1) দিয়ে ১ সেকেন্ড non-blocking sleep করানো হয়েছে — await keyword এই coroutine-টিকে pause করে দেয় এবং event loop কে অন্য ready coroutine চালানোর সুযোগ দেয়; blocking না করাই async-এর মূল শক্তি
print(name)স্লিপ শেষ হয়ে coroutine resume করার পর name variable-এর মান ("A" অথবা "B") কনসোলে প্রিন্ট করা হয়
async def main():"main" নামে top-level entry point async coroutine ডিফাইন করা হয়েছে — এটিই হলো asyncio.run() দ্বারা চালানো প্রথম coroutine
await asyncio.gather(task("A"),task("B"))asyncio.gather() দিয়ে task("A") ও task("B") উভয় coroutine কে একসাথে event loop-এ schedule করা হয়; কাজটি হলো উভয় কাজই সমাপ্ত হওয়া until await করা — দুটোরই ১ সেকেন্ড sleep একসাথে overlap হওয়ায় মোট সময় ~১ সেকেন্ড (২ সেকেন্ড না হয়ে)
asyncio.run(main())asyncio event loop তৈরি করে main() coroutine-টিকে schedule ও চালানো হয় এবং সব কাজ শেষে loop স্বয়ংক্রিয়ভাবে close হয় — এটাই async program-এর standard entry point
কেন কাজ করছে?
gather schedules both coroutines so their waiting periods overlap.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Threading concept

সহজ ভাষায়: Threads can be useful for I/O-bound work.

Example

from concurrent.futures import ThreadPoolExecutor
with ThreadPoolExecutor(max_workers=2) as ex:
    print(list(ex.map(lambda x:x*x,[1,2,3])))

Line-by-line explanation

from concurrent.futures import ThreadPoolExecutorconcurrent.futures মডিউল থেকে ThreadPoolExecutor class import করা হয়েছে — এটি pre-defined thread pool তৈরি করে task execution সহজ করে দেয়
with ThreadPoolExecutor(max_workers=2) as ex:max_workers=2 সেট করে মোট ২টি worker thread থেকে একটি thread pool তৈরি করা হয়েছে; context manager (with statement) ব্যবহার করায় কাজ শেষে pool স্বয়ংক্রিয়ভাবে shutdown ও threads cleanup হয়
print(list(ex.map(lambda x:x*x,[1,2,3])))ex.map() দিয়ে [1,2,3] list-র প্রতিটি উপাদানে lambda x:x*x (সংখ্যার বর্গ) ফাংশনটি thread pool-এর মাধ্যমে distributedভাবে চালানো হয়; সব worker থেকে ফলাফল sequentially list আকারে জমা হয়ে [1, 4, 9] প্রিন্ট হয়
কেন কাজ করছে?
A pool manages worker threads for the submitted tasks.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Multiprocessing concept

সহজ ভাষায়: Separate processes can use multiple CPU cores for CPU-heavy work.

Example

from concurrent.futures import ProcessPoolExecutor
with ProcessPoolExecutor() as ex:
    print(list(ex.map(lambda x:x*x,[1,2,3])))

Line-by-line explanation

from concurrent.futures import ProcessPoolExecutorconcurrent.futures মডিউল থেকে ProcessPoolExecutor class import করা হয়েছে — threads না করে আলাদা আলাদা OS process তৈরি করে, যা Python GIL (Global Interpreter Lock) কে bypass করতে পারে
with ProcessPoolExecutor() as ex:Process Pool তৈরি করা হয়েছে — কোনো max_workers না দিলে স্বয়ংক্রিয়ভাবে CPU-র total core সংখ্যা অনুযায়ী worker process assign হয়; context manager দিয়ে শেষে processes সঠিকভাবে terminate হয়
print(list(ex.map(lambda x:x*x,[1,2,3])))প্রতিটি list উপাদানের বর্গ (x*x) আলাদা আলাদা child process-এ parallelভাবে run করা হয় (true multi-core parallelism); IPC (Inter-Process Communication) করে ফলাফল parent process-এ ফিরে আসে এবং list হিসেবে [1,4,9] প্রিন্ট হয়
কেন কাজ করছে?
Processes have separate Python runtimes and are useful for CPU-bound workloads.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
