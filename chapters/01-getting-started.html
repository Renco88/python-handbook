Getting Started

Python কী, interpreter, comments, print(), variables, naming, input/output, type(), casting

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. What is Python?

সহজ ভাষায়: Python is a high-level programming language designed to make programs readable.

Example

print("Hello, Python!")

Line-by-line explanation

print("Hello, Python!")
কেন কাজ করছে?
print() asks Python to display a value. The string is inside quotes, so Python treats it as text.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Variables

সহজ ভাষায়: A variable is a name that refers to a value. Think of it as a label attached to information.

Example

name = "Mahadi"
age = 25
print(name)
print(age)

Line-by-line explanation

name = "Mahadi"
age = 25
print(name)
print(age)
কেন কাজ করছে?
The first line stores text in name. The second stores an integer in age. print() reads those values.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Input

সহজ ভাষায়: input() lets a program receive text from the user.

Example

name = input("What is your name? ")
print(f"Hello, {name}!")

Line-by-line explanation

name = input("What is your name? ")
print(f"Hello, {name}!")
কেন কাজ করছে?
input() returns a string. The f-string inserts the value of name inside the sentence.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Type conversion

সহজ ভাষায়: User input is text, so numeric calculations usually need int() or float().

Example

age = int(input("Age: "))
print(age + 1)

Line-by-line explanation

age = int(input("Age: "))
print(age + 1)
কেন কাজ করছে?
int() converts the typed characters into an integer. Now + performs numeric addition.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
