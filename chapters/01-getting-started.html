Getting Started

Python কী, interpreter, comments, print(), variables, naming, input/output, type(), casting

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. What is Python?

সহজ ভাষায়: Python is a high-level programming language designed to make programs readable.

Example

print("Hello, Python!")

Line-by-line explanation

print("Hello, Python!") কনসোলে "Hello, Python!" টেক্সটটি প্রদর্শন করে — print() ফাংশন ব্র্যাকেটের ভিতরের মানটি আউটপুট হিসেবে দেখায়।
কেন কাজ করছে?
print() asks Python to display a value. The string is inside quotes, so Python treats it as text.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Variables

সহজ ভাষায়: A variable is a name that refers to a value. Think of it as a label attached to information.

Example

name = "Mahadi"
age = 25
print(name)
print(age)

Line-by-line explanation

name = "Mahadi" "Mahadi" স্ট্রিং (টেক্সট) মানটি name নামের ভেরিয়েবলে সংরক্ষণ করে — = চিহ্ন assignment operator, ডানদিকের মানটি বামদিকের নামে বাঁধাই করে।
age = 25 25 পূর্ণসংখ্যাটি age নামের ভেরিয়েবলে সংরক্ষণ করে — ইন্টিজার টাইপের মান সরাসরি লেখা হয়, কোনো কোটেশন দরকার নয়।
print(name) name ভেরিয়েবলের মধ্যে সংরক্ষিত মানটি ("Mahadi") কনসোলে প্রদর্শন করে — ভেরিয়েবল নামটি কোটেশনের বাইরে থাকলে Python তার মানটি বের করে।
print(age) age ভেরিয়েবলের মধ্যে সংরক্ষিত মানটি (25) কনসোলে প্রদর্শন করে — print() ফাংশন int মানটিকেও স্বয়ংক্রিয়ভাবে দেখাতে পারে।
কেন কাজ করছে?
The first line stores text in name. The second stores an integer in age. print() reads those values.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Input

সহজ ভাষায়: input() lets a program receive text from the user.

Example

name = input("What is your name? ")
print(f"Hello, {name}!")

Line-by-line explanation

name = input("What is your name? ") ব্যবহারকারীকে "What is your name? " প্রম্পট দেখায়, তারপর ব্যবহারকারী যা টাইপ করে Enter চাপে — সেই টেক্সটটি input() ফাংশন রিটার্ন করে name ভেরিয়েবলে সংরক্ষণ হয়।
print(f"Hello, {name}!") f-string ব্যবহার করে স্ট্রিংয়ের ভিতরে name ভেরিয়েবলের মানটি সিবদ্ধ করে — {name} স্থানে ব্যবহারকারীর নাম বসে "Hello, [নাম]!" আউটপুট পাওয়া যায়।
কেন কাজ করছে?
input() returns a string. The f-string inserts the value of name inside the sentence.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Type conversion

সহজ ভাষায়: User input is text, so numeric calculations usually need int() or float().

Example

age = int(input("Age: "))
print(age + 1)

Line-by-line explanation

age = int(input("Age: ")) প্রথমে input() দিয়ে ব্যবহারকারীর কাছ থেকে বয়স নেয় (যা স্ট্রিং), তারপর int() ফাংশন দিয়ে সেই স্ট্রিংটিকে পূর্ণসংখ্যাতে রূপান্তর করে age ভেরিয়েবলে রাখে — এভাবে গাণিতিক হিসাব করা যায়।
print(age + 1) age এর পূর্ণসংখ্যার মানের সাথে 1 যোগ করে (numeric addition) ফলাফলটি কনসোলে প্রদর্শন করে — int হয়েছে তাই + হচ্ছে যোগ, স্ট্রিং concatenation নয়।
কেন কাজ করছে?
int() converts the typed characters into an integer. Now + performs numeric addition.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
