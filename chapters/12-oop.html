1. Class and object

সহজ ভাষায়: A class is a blueprint; an object is an instance created from it.

Example

class Student:
    def __init__(self, name):
        self.name = name

s = Student("Renco")
print(s.name)

Line-by-line explanation

class Student:
def __init__(self, name):
self.name = name
s = Student("Renco")
print(s.name)
কেন কাজ করছে?
__init__ initializes each new object. self refers to the current object.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Instance method

সহজ ভাষায়: Methods operate on object data.

Example

class Student:
    def __init__(self,name): self.name=name
    def introduce(self): return f"I am {self.name}"
print(Student("Renco").introduce())

Line-by-line explanation

class Student:
def __init__(self,name): self.name=name
def introduce(self): return f"I am {self.name}"
print(Student("Renco").introduce())
কেন কাজ করছে?
The method uses self.name from the specific object.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Inheritance and overriding

সহজ ভাষায়: A child class can inherit and replace behavior from a parent.

Example

class Animal:
    def speak(self): return "sound"
class Dog(Animal):
    def speak(self): return "woof"
print(Dog().speak())

Line-by-line explanation

class Animal:
def speak(self): return "sound"
class Dog(Animal):
def speak(self): return "woof"
print(Dog().speak())
কেন কাজ করছে?
Dog inherits Animal but overrides speak. This is a simple polymorphic pattern.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Encapsulation and abstraction

সহজ ভাষায়: Internal details can be protected behind methods; abstract classes define required behavior.

Example

from abc import ABC, abstractmethod
class Shape(ABC):
    @abstractmethod
    def area(self): pass
class Square(Shape):
    def __init__(self,s): self.s=s
    def area(self): return self.s*self.s
print(Square(4).area())

Line-by-line explanation

from abc import ABC, abstractmethod
class Shape(ABC):
@abstractmethod
def area(self): pass
class Square(Shape):
def __init__(self,s): self.s=s
def area(self): return self.s*self.s
print(Square(4).area())
কেন কাজ করছে?
The abstract interface says every Shape must provide area().
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
