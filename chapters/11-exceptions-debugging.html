Exceptions & Debugging

tracebacks, try/except/else/finally, raise, custom exceptions, assertions and debugging

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. Reading a traceback

সহজ ভাষায়: A traceback tells you where an exception happened and what type it was.

Example

numbers = [1,2]
print(numbers[5])

Line-by-line explanation

numbers = [1,2]
print(numbers[5])
কেন কাজ করছে?
IndexError tells us the requested index does not exist.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. try / except

সহজ ভাষায়: Handle expected runtime problems without crashing the whole program.

Example

try:
    n=int(input("Number: "))
    print(10/n)
except ValueError:
    print("Enter an integer")
except ZeroDivisionError:
    print("Zero is not allowed")

Line-by-line explanation

try:
n=int(input("Number: "))
print(10/n)
except ValueError:
print("Enter an integer")
except ZeroDivisionError:
print("Zero is not allowed")
কেন কাজ করছে?
Each except handles a particular failure.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. raise

সহজ ভাষায়: raise lets your program reject invalid state explicitly.

Example

def withdraw(balance, amount):
    if amount > balance:
        raise ValueError("Insufficient balance")
    return balance-amount

Line-by-line explanation

def withdraw(balance, amount):
if amount > balance:
raise ValueError("Insufficient balance")
return balance-amount
কেন কাজ করছে?
The function creates a clear error when the business rule is violated.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. finally

সহজ ভাষায়: finally runs whether an exception happened or not.

Example

try:
    print(10/2)
finally:
    print("Cleanup")

Line-by-line explanation

try:
print(10/2)
finally:
print("Cleanup")
কেন কাজ করছে?
Cleanup code can be placed in finally.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
