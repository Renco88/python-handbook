Typing, Testing & Clean Code

type hints, docstrings, pytest concepts, assertions, logging, project structure and style

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. Type hints

সহজ ভাষায়: Type hints document intended types and help tools detect mistakes.

Example

def add(a: int, b: int) -> int:
    return a + b

Line-by-line explanation

def add(a: int, b: int) -> int:
return a + b
কেন কাজ করছে?
The annotations say what types the function expects and returns.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Assertions

সহজ ভাষায়: Assertions check assumptions during development and tests.

Example

def add(a,b): return a+b
assert add(2,3) == 5

Line-by-line explanation

def add(a,b): return a+b
assert add(2,3) == 5
কেন কাজ করছে?
If the condition is false, Python raises AssertionError.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Logging

সহজ ভাষায়: Logging records useful runtime information.

Example

import logging
logging.basicConfig(level=logging.INFO)
logging.info("Application started")

Line-by-line explanation

import logging
logging.basicConfig(level=logging.INFO)
logging.info("Application started")
কেন কাজ করছে?
Logging is preferable to scattered print statements in larger applications.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Clean project structure

সহজ ভাষায়: Separate application code, tests, configuration and documentation as a project grows.

Example

project/
  src/
  tests/
  README.md
  pyproject.toml

Line-by-line explanation

project/
src/
tests/
README.md
pyproject.toml
কেন কাজ করছে?
A predictable structure makes collaboration and maintenance easier.
