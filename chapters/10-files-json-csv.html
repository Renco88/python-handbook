Files, JSON & CSV

open(), with, pathlib, read/write/append, JSON, CSV and data persistence

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. Writing a file

সহজ ভাষায়: open() with mode w creates or overwrites a file.

Example

with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("Hello Python")

Line-by-line explanation

with open("notes.txt", "w", encoding="utf-8") as f:
f.write("Hello Python")
কেন কাজ করছে?
with manages the file lifecycle and closes it after the block.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Reading a file

সহজ ভাষায়: read() loads the contents as text.

Example

with open("notes.txt", "r", encoding="utf-8") as f:
    content = f.read()
print(content)

Line-by-line explanation

with open("notes.txt", "r", encoding="utf-8") as f:
content = f.read()
print(content)
কেন কাজ করছে?
The file is opened for reading and the text is assigned to content.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. JSON

সহজ ভাষায়: JSON represents structured data and maps naturally to Python dictionaries and lists.

Example

import json
data={"name":"Renco","skills":["Python","React"]}
text=json.dumps(data, indent=2)
print(text)

Line-by-line explanation

import json
data={"name":"Renco","skills":["Python","React"]}
text=json.dumps(data, indent=2)
print(text)
কেন কাজ করছে?
dumps converts Python data to JSON text.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. CSV

সহজ ভাষায়: CSV stores tabular data as rows and columns.

Example

import csv
with open("students.csv", newline="", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        print(row["name"])

Line-by-line explanation

import csv
with open("students.csv", newline="", encoding="utf-8") as f:
for row in csv.DictReader(f):
print(row["name"])
কেন কাজ করছে?
DictReader turns each row into a dictionary keyed by the header.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
