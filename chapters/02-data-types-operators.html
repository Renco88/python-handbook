Data Types & Operators

int, float, bool, str, None, arithmetic, comparison, logical, assignment, membership, identity

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. Integers and floats

সহজ ভাষায়: int represents whole numbers; float represents numbers with decimal parts.

Example

a = 10
b = 2.5
print(a + b)
print(type(b))

Line-by-line explanation

a = 10
b = 2.5
print(a + b)
print(type(b))
কেন কাজ করছে?
Python stores 10 as an int and 2.5 as a float. type() lets you inspect the type.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Arithmetic operators

সহজ ভাষায়: Arithmetic operators calculate values: +, -, *, /, //, %, **.

Example

x = 17
y = 5
print(x + y)
print(x // y)
print(x % y)
print(x ** 2)

Line-by-line explanation

x = 17
y = 5
print(x + y)
print(x // y)
print(x % y)
print(x ** 2)
কেন কাজ করছে?
// gives floor division, % gives the remainder, and ** raises a number to a power.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Comparison

সহজ ভাষায়: Comparison operators return True or False.

Example

age = 20
print(age >= 18)
print(age == 20)

Line-by-line explanation

age = 20
print(age >= 18)
print(age == 20)
কেন কাজ করছে?
The first expression asks whether age is at least 18. The second checks equality.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Logical operators

সহজ ভাষায়: and, or and not combine Boolean conditions.

Example

age = 20
has_id = True
print(age >= 18 and has_id)

Line-by-line explanation

age = 20
has_id = True
print(age >= 18 and has_id)
কেন কাজ করছে?
Both conditions must be true for and to produce True.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
