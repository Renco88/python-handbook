1. Integers and floats

সহজ ভাষায়: int represents whole numbers; float represents numbers with decimal parts.

Example

a = 10
b = 2.5
print(a + b)
print(type(b))

Line-by-line explanation

a = 10 10 পূর্ণসংখ্যাটি a ভেরিয়েবলে সংরক্ষণ করে — এটি int (পূর্ণসংখ্যা) টাইপের ডেটা, কোনো দশমিক বিন্দু নেই তাই int ধরে।
b = 2.5 2.5 দশমিক সংখ্যাটি b ভেরিয়েবলে সংরক্ষণ করে — এটি float (ভাসমান দশমিক) টাইপ, দশমিক বিন্দু থাকলে Python স্বয়ংক্রিয়ভাবে float টাইপ ধরে নেয়।
print(a + b) a (10) ও b (2.5) এর যোগফল গণনা করে 12.5 কনসোলে প্রদর্শন করে — int ও float যোগ করলে Python ফলাফলকে float (12.5) হিসেবে দেয় (type promotion)।
print(type(b)) type() ফাংশন b ভেরিয়েবলের ডেটা টাইপ বের করে প্রদর্শন করে — কোনো ভেরিয়েবলের ধরন চেক করার জন্য সবসময় type() ব্যবহার করা যায়।
কেন কাজ করছে?
Python stores 10 as an int and 2.5 as a float. type() lets you inspect the type.

2. Arithmetic operators

সহজ ভাষায়: Arithmetic operators calculate values: +, -, *, /, //, %, **.

Example

x = 17
y = 5
print(x + y)
print(x // y)
print(x % y)
print(x ** 2)

Line-by-line explanation

x = 17 17 পূর্ণসংখ্যাটি x ভেরিয়েবলে সংরক্ষণ করে — divisor হিসেবে এটি ব্যবহার হবে।
y = 5 5 পূর্ণসংখ্যাটি y ভেরিয়েবলে সংরক্ষণ করে — divisor হিসেবে এটি ব্যবহার হবে।
print(x + y) x ও y এর যোগফল 17 + 5 = 22 কনসোলে প্রদর্শন করে — + হলো addition operator, দুটি সংখ্যার যোগফল বের করে।
print(x // y) x কে y দিয়ে ভাগ করে floor division (নিচের দিকে পূর্ণসাংখ্যিক ভাগফল) 3 প্রদর্শন করে — 17 ÷ 5 = 3.4 কিন্তু // শুধু পূর্ণাংশ 3 রিটার্ন করে, দশমিকাংশ বাদ দেয়।
print(x % y) x কে y দিয়ে ভাগ করে ভাগশেষ (modulo) 2 প্রদর্শন করে — 17 = 5×3 + 2, সবচেয়ে বেশি ভাগ করার পরও 2 বাকি থাকে সেটাই % রিটার্ন করে।
print(x ** 2) x এর ঘাত (exponentiation) বের করে 17² = 289 প্রদর্শন করে — ** হলো পাওয়ার অপারেটর, বামদিকের সংখ্যাটিকে ডানদিকের সংখ্যা ঘাতে উঠায়।
কেন কাজ করছে?
// gives floor division, % gives the remainder, and ** raises a number to a power.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Comparison

সহজ ভাষায়: Comparison operators return True or False.

Example

age = 20
print(age >= 18)
print(age == 20)

Line-by-line explanation

age = 20 20 পূর্ণসংখ্যাটি age ভেরিয়েবলে সংরক্ষণ করে — তুলনা করার জন্য মান সেট করা।
print(age >= 18) comparison operator >= দিয়ে চেক করে age এর মান 18 বা তার বেশি কিনা — 20 >= 18 সত্য (True) তাই Boolean True প্রদর্শন করে। (greater than or equal)
print(age == 20) equality operator == দিয়ে চেক করে age এর মান ঠিক 20 কিনা — সমান তাই Boolean True প্রদর্শন করে। গুরুত্বপূর্ণ: = assignment, == তুলনা — দুটো সম্পূর্ণ ভিন্ন।
কেন কাজ করছে?
The first expression asks whether age is at least 18. The second checks equality.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Logical operators

সহজ ভাষায়: and, or and not combine Boolean conditions.

Example

age = 20
has_id = True
print(age >= 18 and has_id)

Line-by-line explanation

age = 20 20 পূর্ণসংখ্যাটি age ভেরিয়েবলে সংরক্ষণ করে — প্রথম শর্তের জন্য মান।
has_id = True Boolean মান True টি has_id ভেরিয়েবলে সংরক্ষণ করে — bool টাইপের শুধু দুটি মান থাকে: True বা False, দ্বিতীয় শর্তের জন্য এটি ব্যবহার হবে।
print(age >= 18 and has_id) logical and অপারেটর দুটি শর্ত একসাথে চেক করে — age>=18 সত্য (True) এবং has_id=True সত্য, দুটোই সত্য তাই চূড়ান্ত ফলাফল True। and শুধু তখনই True যখন দুটি শর্তই আলাদাভাবে সত্য হয়।
কেন কাজ করছে?
Both conditions must be true for and to produce True.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
