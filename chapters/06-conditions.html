Conditions

if, elif, else, nested decisions, truthiness, compound conditions and real decisions

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. if / else

সহজ ভাষায়: Conditional statements let a program choose a path.

Example

marks = 82
if marks >= 80:
    print("A+")
else:
    print("Keep practicing")

Line-by-line explanation

marks = 82 82 পূর্ণসংখ্যাটি marks ভেরিয়েবলে সংরক্ষণ করে — যা দিয়ে পরে শর্ত পরীক্ষা (conditional check) করা হবে।
if marks >= 80: প্রথম শর্ত চেক করে: marks এর মান 80 বা তার বেশি কিনা? if লাইনের শেষে অবশ্যই কোলন : দিতে হবে — এটি Python কে বলে এরপর একটি ইন্ডেন্টেড ব্লক শুরু হচ্ছে। যেহেতু 82 ≥ 80, শর্তটি সত্য (True)।
print("A+") if-এর সাথে সংযুক্ত ইন্ডেন্টেড (4 স্পেস) ব্লক — যেহেতু উপরের শর্তটি সত্য, তাই এই লাইনটি কার্যকর হয় এবং কনসোলে "A+" প্রদর্শন করে। Python-এ ইন্ডেন্টেশন দিয়েই কোনো ব্লক শুরু ও শেষ বোঝানো হয়।
else: else কীওয়ার্ড — যার অর্থ 'অন্যথায়'। যদি উপরের if শর্তটি মিথ্যা হতো, তাহলে else-এর পরের ব্লক কার্যকর হত; এখানে if সত্য হওয়ায় else এর ব্লক সম্পূর্ণ বাইপাস (বাদ দেওয়া) হয়। শেষে কোলন : দিতে হবে।
print("Keep practicing") else-এর ইন্ডেন্টেড ব্লক — শুধুমাত্র যখন if শর্তটি মিথ্যা (False) হয়, তখনই এই লাইনটি চালানো হতো এবং "Keep practicing" প্রদর্শন করতো। এখানে if সত্য তাই এটি কখনো চলে না।
কেন কাজ করছে?
Python evaluates the condition. Only the matching indented block runs.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. elif

সহজ ভাষায়: elif handles additional alternatives.

Example

marks = 72
if marks >= 80:
    grade = "A+"
elif marks >= 70:
    grade = "A"
else:
    grade = "Below A"
print(grade)

Line-by-line explanation

marks = 72 72 পূর্ণসংখ্যাটি marks ভেরিয়েবলে সংরক্ষণ করে।
if marks >= 80: প্রথম শর্ত: 72 ≥ 80? উত্তর না — মিথ্যা (False)। তাই if-এর ব্লকটি চালানো হবে না, পরবর্তী elif শর্তের দিকে এগিয়ে যাবে।
grade = "A+" প্রথম শর্ত সত্য হলে grade এ "A+" সেট করতো — কিন্তু 72<80 তাই এই লাইন কখনো কার্যকর হয় না।
elif marks >= 70: 'else if' এর সংক্ষিপ্ত রূপ elif — প্রথম if শর্ত মিথ্যা হলেই এই elif শর্তটি চেক করা হয়। 72 ≥ 70? হ্যাঁ সত্য (True)। তাই অবিলম্বে এই ব্লকে ঢুকে পরে, পরের else আর কখনো চেক করা হবে না।
grade = "A" elif শর্ত সত্য হওয়ায় grade ভেরিয়েবলে "A" মানটি সেট করে — এখানে পৌঁছে গেলে আর পরের শর্তগুলো (else) চেক করা হয় না, কারণ elif-এর ক্রম উপর থেকে নিচে, যেটা প্রথমে মিলে সেটাই চালু হয়।
else: if ও সব elif শর্ত মিথ্যা হলে last resort হিসেবে else ব্লকটি চালানো হয়। এখানে ঠিক আগের elif সত্য হয়েছে তাই এই else ব্লকে কখনোই আসা হয় না।
grade = "Below A" else ব্লকের কোড — যদি marks < 70 হতো, তাহলে grade এ "Below A" সেট হতো।
print(grade) সব শর্ত চেক শেষে grade এর বর্তমান মান "A" কনসোলে প্রদর্শন করে — এই লাইনটি কোনো ইন্ডেন্টেড ব্লকের ভিতরে না থাকায় সবসময়ই চলছে।
কেন কাজ করছে?
Python checks from top to bottom and stops at the first true branch.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Nested decisions

সহজ ভাষায়: A condition can contain another condition.

Example

username = "admin"
password = "123"
if username == "admin":
    if password == "123":
        print("Access granted")

Line-by-line explanation

username = "admin" "admin" স্ট্রিংটি username নামের ভেরিয়েবলে সংরক্ষণ করে — লগইন চেকের প্রথম ধাপ।
password = "123" "123" স্ট্রিংটি password নামের ভেরিয়েবলে সংরক্ষণ করে — লগইন চেকের দ্বিতীয় ধাপ।
if username == "admin": বাইরের লেভেলের শর্ত: username ভেরিয়েবলের মান ঠিক "admin" কিনা? == দিয়ে value তুলনা করা হয়। সমান তাই সত্য (True), ইন্ডেন্টেড ভেতরের ব্লকে ঢুকে।
if password == "123": ভেতরের লেভেলের (nested) শর্ত — শুধুমাত্র বাইরের if শর্তটি সত্য হলেই এই শর্তটি কখনও চেক করা হয় (username ভুল থাকলে এখানে আসেই না)। password ঠিক "123" তাই এটাও সত্য, আরো ভেতরের ব্লকে ঢুকে।
print("Access granted") সবচেয়ে ভেতরের (দ্বিগুণ ইন্ডেন্টেড) লাইন — উভয় শর্তই আলাদাভাবে সত্য হওয়ায় "Access granted" প্রদর্শন করে। username ভুল থাকলে এখানে আসতো না; আবার username ঠিক থাকলেও password ভুল থাকলেও কখনো আসতো না।
কেন কাজ করছে?
The second check only runs when the username check succeeds.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Truthiness

সহজ ভাষায়: Many values can be treated as true or false in a condition.

Example

items = []
if not items:
    print("The list is empty")

Line-by-line explanation

items = [] third bracket [ ] দিয়ে একটি খালি লিস্ট (empty list) তৈরি করে items ভেরিয়েবলে রাখে — Python-এ খালি কালেকশনকে 'falsy' হিসেবে গণ্য করা হয়, অর্থাৎ শর্তে বসলে False ধরা হয়।
if not items: items-এর ট্রুথনেস চেক করে — items = খালি লিস্ট (falsy value), তাই not items = True হয়। সূত্র: 0, খালি স্ট্রিং "", None, খালি লিস্ট [], খালি ডিকশনারি {}, খালি টাপল () — সবগুলো falsy; nonzero সংখ্যা, non-empty স্ট্রিং/লিস্ট সবগুলো truthy।
print("The list is empty") উপরের শর্ত not items True হওয়ায় এই লাইনটি চালায় এবং "The list is empty" প্রদর্শন করে — এভাবে লুজিক্যালি খালি কিনা সেরকম চেক করা Python-এর regular শ্রেষ্ঠ অভ্যাস।
কেন কাজ করছে?
An empty list is falsy, so not items becomes True.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
