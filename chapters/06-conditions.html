Conditions

if, elif, else, nested decisions, truthiness, compound conditions and real decisions

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. if / else

সহজ ভাষায়: Conditional statements let a program choose a path.

Example

marks = 82
if marks >= 80:
    print("A+")
else:
    print("Keep practicing")

Line-by-line explanation

marks = 82
if marks >= 80:
print("A+")
else:
print("Keep practicing")
কেন কাজ করছে?
Python evaluates the condition. Only the matching indented block runs.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. elif

সহজ ভাষায়: elif handles additional alternatives.

Example

marks = 72
if marks >= 80:
    grade = "A+"
elif marks >= 70:
    grade = "A"
else:
    grade = "Below A"
print(grade)

Line-by-line explanation

marks = 72
if marks >= 80:
grade = "A+"
elif marks >= 70:
grade = "A"
else:
grade = "Below A"
print(grade)
কেন কাজ করছে?
Python checks from top to bottom and stops at the first true branch.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Nested decisions

সহজ ভাষায়: A condition can contain another condition.

Example

username = "admin"
password = "123"
if username == "admin":
    if password == "123":
        print("Access granted")

Line-by-line explanation

username = "admin"
password = "123"
if username == "admin":
if password == "123":
print("Access granted")
কেন কাজ করছে?
The second check only runs when the username check succeeds.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Truthiness

সহজ ভাষায়: Many values can be treated as true or false in a condition.

Example

items = []
if not items:
    print("The list is empty")

Line-by-line explanation

items = []
if not items:
print("The list is empty")
কেন কাজ করছে?
An empty list is falsy, so not items becomes True.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
