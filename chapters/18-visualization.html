Visualization

Matplotlib line/scatter/bar/histogram, labels, legends, subplots and storytelling

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. Line plot

সহজ ভাষায়: Line plots show trends across an ordered x-axis.

Example

import matplotlib.pyplot as plt
plt.plot([1,2,3,4],[2,4,3,6])
plt.xlabel("Day")
plt.ylabel("Value")
plt.show()

Line-by-line explanation

import matplotlib.pyplot as pltMatplotlib-এর pyplot মডিউল লোড করে সংক্ষিপ্ত নাম 'plt' হিসেবে বাইন্ড করা হয়েছে
plt.plot([1,2,3,4],[2,4,3,6])x=[1,2,3,4] ও y=[2,4,3,6] ডেটা দিয়ে পয়েন্টগুলোকে সরলরেখা দিয়ে যুক্ত করে লাইন প্লট আঁকা হয়েছে
plt.xlabel("Day")X-অক্ষের নাম/লেবেল 'Day' সেট করা হয়েছে যাতে বোঝা যায় horizontal axis-এ দিনসমূহ আছে
plt.ylabel("Value")Y-অক্ষের নাম/লেবেল 'Value' সেট করা হয়েছে যাতে vertical axis-এ মানগুলো বোঝা যায়
plt.show()Matplotlib figure উইন্ডোতে render করে গ্রাফটি ব্যবহারকারীর কাছে প্রদর্শন করা হয়েছে
কেন কাজ করছে?
plot connects points to reveal a trend.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Scatter plot

সহজ ভাষায়: Scatter plots show relationships between two numeric variables.

Example

plt.scatter([1,2,3,4],[2,5,3,7])
plt.xlabel("X")
plt.ylabel("Y")
plt.show()

Line-by-line explanation

plt.scatter([1,2,3,4],[2,5,3,7])x ও y এর প্রতিটি জোড়া মানকে আলাদা বিন্দু (dot) হিসেবে প্লট করে scatter plot তৈরি করা হয়েছে
plt.xlabel("X")X-অক্ষের লেবেল 'X' সেট করা হয়েছে — এটি প্রথম variable-কে প্রতিনিধিত্ব করে
plt.ylabel("Y")Y-অক্ষের লেবেল 'Y' সেট করা হয়েছে — এটি দ্বিতীয় variable-কে প্রতিনিধিত্ব করে
plt.show()তৈরি করা scatter গ্রাফটি নতুন উইন্ডোতে প্রদর্শন করা হয়েছে
কেন কাজ করছে?
Each point represents one observation.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Histogram

সহজ ভাষায়: Histograms show the distribution of numeric values.

Example

plt.hist([1,2,2,3,3,3,4,5], bins=5)
plt.xlabel("Value")
plt.ylabel("Frequency")
plt.show()

Line-by-line explanation

plt.hist([1,2,2,3,3,3,4,5], bins=5)দেওয়া ডেটার মানগুলোকে ৫টি সমান পরিসর (bin)-এ গ্রুপ করে প্রতিটি bin-এ কতগুলো মান আছে তার ঘনত্ব দেখানো হিস্টোগ্রাম আঁকা হয়েছে
plt.xlabel("Value")X-অক্ষে মূল মান/Value লেবেল সেট করা হয়েছে — এটি original data points-এর range বোঝায়
plt.ylabel("Frequency")Y-অক্ষে ফ্রিকোয়েন্সি/বারবারি লেবেল সেট করা হয়েছে — এটি প্রতিটি বিনে কতগুলো দৃষ্টান্ত/observation পড়েছে তা বোঝায়
plt.show()সম্পূর্ণ histogram figure-কে render করে display উইন্ডোতে প্রদর্শন করা হয়েছে
কেন কাজ করছে?
Values are grouped into bins so you can see where observations concentrate.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Subplots

সহজ ভাষায়: Multiple plots can tell a fuller story in one figure.

Example

fig,ax=plt.subplots(1,2)
ax[0].plot([1,2,3],[2,4,3])
ax[1].scatter([1,2,3],[3,1,4])
plt.show()

Line-by-line explanation

fig,ax=plt.subplots(1,2)১টি সারি ও ২টি কলামের grid-এ দুটি axes (সাবপ্লট) সহ একটি figure container তৈরি করে fig object ও ax array-তে unpack করা হয়েছে
ax[0].plot([1,2,3],[2,4,3])ax array-র প্রথম (index ০) সাবপ্লটে (বাম পাশে) x,y ডেটা দিয়ে লাইন প্লট আঁকা হয়েছে
ax[1].scatter([1,2,3],[3,1,4])ax array-র দ্বিতীয় (index ১) সাবপ্লটে (ডান পাশে) একই x,y ডেটা দিয়ে scatter plot (বিন্দু) আঁকা হয়েছে
plt.show()উভয় সাবপ্লটসহ সম্পূর্ণ figure-কে একসাথে render করে প্রদর্শন করা হয়েছে
কেন কাজ করছে?
subplots creates multiple axes in one figure.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
