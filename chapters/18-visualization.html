Visualization

Matplotlib line/scatter/bar/histogram, labels, legends, subplots and storytelling

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. Line plot

সহজ ভাষায়: Line plots show trends across an ordered x-axis.

Example

import matplotlib.pyplot as plt
plt.plot([1,2,3,4],[2,4,3,6])
plt.xlabel("Day")
plt.ylabel("Value")
plt.show()

Line-by-line explanation

import matplotlib.pyplot as plt
plt.plot([1,2,3,4],[2,4,3,6])
plt.xlabel("Day")
plt.ylabel("Value")
plt.show()
কেন কাজ করছে?
plot connects points to reveal a trend.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

সহজ ভাষায়: Scatter plots show relationships between two numeric variables.

plt.show()

3. Histogram

সহজ ভাষায়: Histograms show the distribution of numeric values.

Example

plt.hist([1,2,2,3,3,3,4,5], bins=5)
plt.xlabel("Value")
plt.ylabel("Frequency")
plt.show()

Line-by-line explanation

plt.hist([1,2,2,3,3,3,4,5], bins=5)
plt.xlabel("Value")
plt.ylabel("Frequency")
plt.show()
কেন কাজ করছে?
Values are grouped into bins so you can see where observations concentrate.

4. Subplots

সহজ ভাষায়: Multiple plots can tell a fuller story in one figure.

Example

fig,ax=plt.subplots(1,2)
ax[0].plot([1,2,3],[2,4,3])
ax[1].scatter([1,2,3],[3,1,4])
plt.show()

Line-by-line explanation

fig,ax=plt.subplots(1,2)
ax[0].plot([1,2,3],[2,4,3])
ax[1].scatter([1,2,3],[3,1,4])
plt.show()
কেন কাজ করছে?
subplots creates multiple axes in one figure.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
