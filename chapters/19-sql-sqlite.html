SQL & SQLite

database concepts, tables, CRUD, parameterized queries and Python database workflow

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. Create a database

সহজ ভাষায়: SQLite stores structured data in a local file.

Example

import sqlite3
con=sqlite3.connect("app.db")
cur=con.cursor()
cur.execute("CREATE TABLE IF NOT EXISTS users(id INTEGER PRIMARY KEY,name TEXT)")
con.commit()

Line-by-line explanation

import sqlite3
con=sqlite3.connect("app.db")
cur=con.cursor()
cur.execute("CREATE TABLE IF NOT EXISTS users(id INTEGER PRIMARY KEY,name TEXT)")
con.commit()
কেন কাজ করছে?
connect opens the database; execute sends SQL to SQLite.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Insert safely

সহজ ভাষায়: Use parameters rather than string concatenation.

Example

cur.execute("INSERT INTO users(name) VALUES (?)", ("Renco",))
con.commit()

Line-by-line explanation

cur.execute("INSERT INTO users(name) VALUES (?)", ("Renco",))
con.commit()
কেন কাজ করছে?
The ? placeholder prevents data from being treated as SQL syntax.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Read data

সহজ ভাষায়: SELECT returns rows that you can fetch from Python.

Example

rows=cur.execute("SELECT id,name FROM users").fetchall()
print(rows)

Line-by-line explanation

rows=cur.execute("SELECT id,name FROM users").fetchall()
print(rows)
কেন কাজ করছে?
fetchall collects the query results.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. CRUD mindset

সহজ ভাষায়: Create, Read, Update and Delete cover the basic lifecycle of stored records.

Example

cur.execute("UPDATE users SET name=? WHERE id=?", ("Mahadi",1))
con.commit()

Line-by-line explanation

cur.execute("UPDATE users SET name=? WHERE id=?", ("Mahadi",1))
con.commit()
কেন কাজ করছে?
Parameterized SQL keeps values separate from the query text.
