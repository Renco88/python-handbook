SQL & SQLite

database concepts, tables, CRUD, parameterized queries and Python database workflow

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. Create a database

সহজ ভাষায়: SQLite stores structured data in a local file.

Example

import sqlite3
con=sqlite3.connect("app.db")
cur=con.cursor()
cur.execute("CREATE TABLE IF NOT EXISTS users(id INTEGER PRIMARY KEY,name TEXT)")
con.commit()

Line-by-line explanation

import sqlite3Python-এর বিল্ট-ইন sqlite3 মডিউল লোড করা হয়েছে যা SQLite ডাটাবেসের সাথে কাজ করতে সক্ষম
con=sqlite3.connect("app.db")বর্তমান directory-তে app.db নামের লোকাল ডাটাবেস ফাইলের সাথে কানেকশন/লিংক স্থাপন করা হয়েছে (ফাইল না থাকলে নিজে তৈরি হয়)
cur=con.cursor()কানেকশন থেকে একটি cursor অবজেক্ট তৈরি করা হয়েছে — cursor হলো মাধ্যম যার মাধ্যমে SQL query পাঠানো ও ফলাফল নেওয়া হয়
cur.execute("CREATE TABLE IF NOT EXISTS users(id INTEGER PRIMARY KEY,name TEXT)")users নামের টেবিল যদি আগে থেকে না থাকে তাহলে তৈরি করা হয়: id হলো integer প্রাইমারি কী (অটো ইনক্রিমেন্ট) এবং name হলো text কলাম
con.commit()memory-তে থাকা সব pending ডাটাবেস পরিবর্তনকে স্থায়ীভাবে ফাইলে সংরক্ষণ (persist) করা হয়েছে — commit না করলে পরিবর্তন বাঁচে না
কেন কাজ করছে?
connect opens the database; execute sends SQL to SQLite.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Insert safely

সহজ ভাষায়: Use parameters rather than string concatenation.

Example

cur.execute("INSERT INTO users(name) VALUES (?)", ("Renco",))
con.commit()

Line-by-line explanation

cur.execute("INSERT INTO users(name) VALUES (?)", ("Renco",))users টেবিলে name কলামে নতুন রো যোগ করা হয়েছে — ? হলো parameter placeholder যাতে "Renco" value টি safely বসে এবং SQL injection attack প্রতিরোধ হয়; tuple-এর শেষে comma (,) দরকার single-element tuple-এর জন্য
con.commit()INSERT operation-টি স্থায়ীভাবে ডাটাবেস ফাইলে সংরক্ষণ করা হয়েছে — commit না করলে program exit-এর পর রোটি চলে যাবে
কেন কাজ করছে?
The ? placeholder prevents data from being treated as SQL syntax.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Read data

সহজ ভাষায়: SELECT returns rows that you can fetch from Python.

Example

rows=cur.execute("SELECT id,name FROM users").fetchall()
print(rows)

Line-by-line explanation

rows=cur.execute("SELECT id,name FROM users").fetchall()users টেবিলের সব রো থেকে শুধু id ও name কলাম বেছে নেয়া হয়েছে এবং fetchAll() দিয়ে সব রোকে tuple-এর list হিসেবে rows variable-এ ফেরত নেওয়া হয়েছে
print(rows)fetch করা সব রো (প্রতিটি রো একটি tuple) কে কনসোলে প্রিন্ট করা হয়েছে যাতে ডেটা দেখা যায়
কেন কাজ করছে?
fetchall collects the query results.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. CRUD mindset

সহজ ভাষায়: Create, Read, Update and Delete cover the basic lifecycle of stored records.

Example

cur.execute("UPDATE users SET name=? WHERE id=?", ("Mahadi",1))
con.commit()

Line-by-line explanation

cur.execute("UPDATE users SET name=? WHERE id=?", ("Mahadi",1))users টেবিলে যে সব রোর id = 1, শুধু সেই রোগুলোর name কলামের মান পরিবর্তন করে "Mahadi" সেট করা হয়েছে — দুটি ? placeholder-এ sequentially ("Mahadi", ১) value গুলো বসেছে parameterizedভাবে
con.commit()UPDATE operation-টিকে স্থায়ীভাবে ডাটাবেস ফাইলে লিখে দেওয়া হয়েছে — commit ছাড়া পরিবর্তন temporary থাকে
কেন কাজ করছে?
Parameterized SQL keeps values separate from the query text.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
