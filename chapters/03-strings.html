Strings

indexing, slicing, methods, escaping, f-strings, formatting and text processing

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. Indexing

সহজ ভাষায়: A string is a sequence, so each character has a position.

Example

word = "Python"
print(word[0])
print(word[-1])

Line-by-line explanation

word = "Python"
print(word[0])
print(word[-1])
কেন কাজ করছে?
Index 0 is the first character. Index -1 is the last character.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Slicing

সহজ ভাষায়: Slicing extracts a range using start:stop:step.

Example

word = "Python"
print(word[0:3])
print(word[::-1])

Line-by-line explanation

word = "Python"
print(word[0:3])
print(word[::-1])
কেন কাজ করছে?
The stop position is excluded. [::-1] walks through the string backwards.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. String methods

সহজ ভাষায়: Methods perform common text operations.

Example

name = "  mahadi hassan  "
print(name.strip().title())
print(name.replace("hassan", "renco"))

Line-by-line explanation

name = " mahadi hassan "
print(name.strip().title())
print(name.replace("hassan", "renco"))
কেন কাজ করছে?
strip removes outer whitespace, title changes capitalization, and replace creates a changed string.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. f-strings

সহজ ভাষায়: f-strings make formatted output readable.

Example

name = "Renco"
score = 92
print(f"{name} scored {score}%")

Line-by-line explanation

name = "Renco"
score = 92
print(f"{name} scored {score}%")
কেন কাজ করছে?
Expressions inside braces are evaluated and inserted into the text.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
