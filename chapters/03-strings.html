1. Indexing

সহজ ভাষায়: A string is a sequence, so each character has a position.

Example

word = "Python"
print(word[0])
print(word[-1])

Line-by-line explanation

word = "Python" "Python" স্ট্রিংটি word ভেরিয়েবলে সংরক্ষণ করে — স্ট্রিং হচ্ছে অক্ষরগুলোর একটি ক্রম (sequence of characters), প্রতিটি অক্ষরের একটি নির্দিষ্ট পজিশন থাকে।
print(word[0]) word স্ট্রিংয়ের 0 নং index এর অক্ষর 'P' প্রদর্শন করে — Python-এ সব sequence-এর indexing সবসময় 0 থেকে শুরু হয়, তাই প্রথম অক্ষরের ইনডেক্স 0, দ্বিতীয়টি 1, ইত্যাদি।
print(word[-1]) word স্ট্রিংয়ের শেষ অক্ষর 'n' প্রদর্শন করে — নেগেটিভ ইনডেক্স শেষ থেকে পিছন দিকে গণনা শুরু করে, -1 হলো সবচেয়ে শেষের অক্ষর, -2 হলে আগেরটি।
কেন কাজ করছে?
Index 0 is the first character. Index -1 is the last character.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Slicing

সহজ ভাষায়: Slicing extracts a range using start:stop:step.

Example

word = "Python"
print(word[0:3])
print(word[::-1])

Line-by-line explanation

word = "Python" "Python" স্ট্রিংটি word ভেরিয়েবলে সংরক্ষণ করে।
print(word[0:3]) word স্ট্রিংয়ের 0 থেকে 2 নং index পর্যন্ত অংশ "Pyt" প্রদর্শন করে — slicing syntax [start:stop] ব্যবহার হয়, stop ইনডেক্সটি সবসময় বাদ দেওয়া হয় (এখানে 3 অন্তর্ভুক্ত নয়, তাই 0,1,2 নেওয়া হয়)।
print(word[::-1]) word স্ট্রিংটিকে সম্পূর্ণ উল্টো করে "nohtyP" প্রদর্শন করে — [start:stop:step] extended slicing, step = -1 মানে পিছন থেকে শুরু করে এক এক ধাপ করে আগের দিকে অক্ষর নেওয়া।
কেন কাজ করছে?
The stop position is excluded. [::-1] walks through the string backwards.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. String methods

সহজ ভাষায়: Methods perform common text operations.

Example

name = "  mahadi hassan  "
print(name.strip().title())
print(name.replace("hassan", "renco"))

Line-by-line explanation

name = " mahadi hassan " সামনে ২টি ও পিছনে ২টি ফাঁকা স্পেস সহ নামটি name ভেরিয়েবলে রাখে — বাস্তবে user input থেকে এভাবে unwanted whitespace থাকতে পারে।
print(name.strip().title()) chain method call: প্রথমে strip() দিয়ে সামনে-পিছনের সব ফাঁকা স্পেস সরায় ("mahadi hassan"), তারপর title() দিয়ে প্রতিটি শব্দের প্রথম অক্ষর বড় করে "Mahadi Hassan" প্রদর্শন করে — ডট দিয়ে একের পর এক মেথড কল করা যায়।
print(name.replace("hassan", "renco")) replace() মেথড স্ট্রিংয়ের ভিতরে প্রথম আর্গুমেন্ট "hassan" খুঁজে প্রতিটি কপিকে দ্বিতীয় আর্গুমেন্ট "renco" দিয়ে পরিবর্তন করে নতুন স্ট্রিং " mahadi renco " রিটার্ন করে — লক্ষ্য: স্পেসগুলো এখনও আছে, কারণ strip() কল করা হয়নি।
কেন কাজ করছে?
strip removes outer whitespace, title changes capitalization, and replace creates a changed string.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. f-strings

সহজ ভাষায়: f-strings make formatted output readable.

Example

name = "Renco"
score = 92
print(f"{name} scored {score}%")

Line-by-line explanation

name = "Renco" "Renco" স্ট্রিংটি name ভেরিয়েবলে সংরক্ষণ করে।
score = 92 92 পূর্ণসংখ্যাটি score ভেরিয়েবলে সংরক্ষণ করে।
print(f"{name} scored {score}%") f-string (formatted string literal) ব্যবহার করে — স্ট্রিংয়ের শুরুতে f প্রিফিক্স দিলে { } ব্রেসের ভিতরে সরাসরি ভেরিয়েবল/এক্সপ্রেশন লিখা যায়, Python সেগুলোর মান বসিয়ে দেয় — ফলে "Renco scored 92%" আউটপুট হয়।
কেন কাজ করছে?
Expressions inside braces are evaluated and inserted into the text.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
