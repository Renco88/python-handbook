1. Features and labels

সহজ ভাষায়: Machine learning learns a relationship between input features and a target label.

Example

X=[[1],[2],[3],[4]]
y=[2,4,6,8]

Line-by-line explanation

X=[[1],[2],[3],[4]]
y=[2,4,6,8]
কেন কাজ করছে?
X contains features; y contains the values we want to predict.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Train/test split

সহজ ভাষায়: Keep unseen data for evaluation.

Example

from sklearn.model_selection import train_test_split
X_train,X_test,y_train,y_test=train_test_split(X,y,test_size=.25,random_state=42)

Line-by-line explanation

from sklearn.model_selection import train_test_split
X_train,X_test,y_train,y_test=train_test_split(X,y,test_size=.25,random_state=42)
কেন কাজ করছে?
The model trains on one subset and is evaluated on data it did not see during training.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Regression

সহজ ভাষায়: Regression predicts a numeric value.

Example

from sklearn.linear_model import LinearRegression
model=LinearRegression().fit(X_train,y_train)
print(model.predict(X_test))

Line-by-line explanation

from sklearn.linear_model import LinearRegression
model=LinearRegression().fit(X_train,y_train)
print(model.predict(X_test))
কেন কাজ করছে?
The model learns coefficients that map features to a numeric prediction.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Classification

সহজ ভাষায়: Classification predicts categories.

Example

from sklearn.tree import DecisionTreeClassifier
model=DecisionTreeClassifier(random_state=42)
model.fit([[0],[1],[2],[3]],["low","low","high","high"])
print(model.predict([[2.5]]))

Line-by-line explanation

from sklearn.tree import DecisionTreeClassifier
model=DecisionTreeClassifier(random_state=42)
model.fit([[0],[1],[2],[3]],["low","low","high","high"])
print(model.predict([[2.5]]))
কেন কাজ করছে?
The target values are categories instead of continuous numbers.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
