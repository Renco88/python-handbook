1. Features and labels

সহজ ভাষায়: Machine learning learns a relationship between input features and a target label.

Example

X=[[1],[2],[3],[4]]
y=[2,4,6,8]

Line-by-line explanation

X=[[1],[2],[3],[4]]Features ম্যাট্রিক্স (input): ৪টি আলাদা sample যেখানে প্রত্যেকটি sample-এ ১টি ফিচার মাত্র — scikit-learn সবসময় 2D shape (rows=sample, cols=features) চায় তাই nested list ব্যবহৃত হয়েছে
y=[2,4,6,8]Target/labels vector (output): প্রতিটি X sample-এর সাথে সম্পর্কিত লেবেল মান — ১D array কারণ প্রতিটি sample-এ শুধু ১টি predicted value আছে
কেন কাজ করছে?
X contains features; y contains the values we want to predict.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Train/test split

সহজ ভাষায়: Keep unseen data for evaluation.

Example

from sklearn.model_selection import train_test_split
X_train,X_test,y_train,y_test=train_test_split(X,y,test_size=.25,random_state=42)

Line-by-line explanation

from sklearn.model_selection import train_test_splitscikit-learn library-এর model_selection মডিউল থেকে train_test_split ফাংশন import করা হয়েছে যা ডেটাকে train ও test অংশে ভাগ করতে ব্যবহৃত হয়
X_train,X_test,y_train,y_test=train_test_split(X,y,test_size=.25,random_state=42)সম্পূর্ণ X ও y ডেটা যথাক্রমে ৭৫% training set (X_train/y_train) ও ২৫% test set (X_test/y_test)-এ র‍্যান্ডমলি split করা হয়েছে; random_state=42 দিলে প্রতিবার একই split পাওয়া যায় (reproducible)
কেন কাজ করছে?
The model trains on one subset and is evaluated on data it did not see during training.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Regression

সহজ ভাষায়: Regression predicts a numeric value.

Example

from sklearn.linear_model import LinearRegression
model=LinearRegression().fit(X_train,y_train)
print(model.predict(X_test))

Line-by-line explanation

from sklearn.linear_model import LinearRegressionscikit-learn-এর linear_model মডিউল থেকে LinearRegression class import করা হয়েছে — এটি ordinary least squares linear regression algorithm implement করে
model=LinearRegression().fit(X_train,y_train)প্রথমে LinearRegression model object তৈরি করে তারপর fit() method call করে training data (X_train features, y_train labels) ওপর মডেলকে train করা হয়; fit() হলো learning step যেখানে intercept ও coefficient বের করা হয়
print(model.predict(X_test))Trained মডেলকে ব্যবহার করে unseen test features (X_test) দিয়ে corresponding numeric predictions বের করা হয়েছে এবং সেগুলো কনসোলে প্রিন্ট করা হয়েছে
কেন কাজ করছে?
The model learns coefficients that map features to a numeric prediction.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Classification

সহজ ভাষায়: Classification predicts categories.

Example

from sklearn.tree import DecisionTreeClassifier
model=DecisionTreeClassifier(random_state=42)
model.fit([[0],[1],[2],[3]],["low","low","high","high"])
print(model.predict([[2.5]]))

Line-by-line explanation

from sklearn.tree import DecisionTreeClassifierscikit-learn-এর tree মডিউল থেকে DecisionTreeClassifier class import করা হয়েছে — এটি hierarchical if/else rule tree তৈরি করে categorical prediction করতে পারে
model=DecisionTreeClassifier(random_state=42)Decision Tree Classifier এর নতুন instance তৈরি করা হয়েছে; random_state=42 দিয়ে split point randomness fix করা হয়েছে যাতে প্রতিবার একই tree structure পাওয়া যায়
model.fit([[0],[1],[2],[3]],["low","low","high","high"])মডেলকে ৪টি input features ([[0], [1], [2], [3]]) এবং সাথে সম্পর্কিত ২টি category labels ("low" for 0,1 এবং "high" for 2,3) দিয়ে train করা হয়েছে
print(model.predict([[2.5]]))নতুন unseen input [[2.5]] (এটি 0-1 low ও 2-3 high-এর মাঝে) দিয়ে model কে category predict করতে বলা হয়েছে এবং predicted class (high) প্রিন্ট করা হয়েছে
কেন কাজ করছে?
The target values are categories instead of continuous numbers.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
