Lists

creation, indexing, slicing, methods, nested lists, copying, comprehensions

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. Creating a list

সহজ ভাষায়: Lists store multiple values in one ordered, mutable collection.

Example

fruits = ["apple", "banana", "mango"]
print(fruits[1])

Line-by-line explanation

fruits = ["apple", "banana", "mango"] তিনটি ফলের নাম (স্ট্রিং) নিয়ে একটি লিস্ট তৈরি করে fruits ভেরিয়েবলে সংরক্ষণ করে — লিস্ট third bracket [ ] দিয়ে তৈরি হয়, elements গুলো কমা দিয়ে আলাদা করা হয়, লিস্ট ordered এবং mutable (পরিবর্তনযোগ্য)।
print(fruits[1]) fruits লিস্টের 1 নং index এর উপাদান "banana" প্রদর্শন করে — লিস্টেও 0 থেকে indexing শুরু হয়, তাই index 0 = apple, index 1 = banana, index 2 = mango।
কেন কাজ করছে?
The list has three elements. Index 1 points to banana.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. List methods

সহজ ভাষায়: append adds, insert places, remove deletes by value, and pop removes and returns an item.

Example

items = [10, 20, 30]
items.append(40)
items.remove(20)
last = items.pop()
print(items, last)

Line-by-line explanation

items = [10, 20, 30] 10, 20, 30 — তিনটি পূর্ণসংখ্যা নিয়ে items নামে একটি লিস্ট তৈরি করে।
items.append(40) items লিস্টের খুব শেষে নতুন উপাদান 40 যোগ করে — লিস্টটি এখন [10, 20, 30, 40] হয়ে যায়। append() সবসময় উপাদানটিকে শেষের দিকে যোগ করে।
items.remove(20) items লিস্টের ভিতর থেকে মান 20 টি খুঁজে এটিকে মুছে ফেলে — লিস্টটি এখন [10, 30, 40] হয়ে যায়। remove() value অনুযায়ী মুছে, index অনুযায়ী নয়।
last = items.pop() items লিস্টের শেষের উপাদান 40 কে লিস্ট থেকে সরিয়ে সেই মানটিকে last ভেরিয়েবলে সংরক্ষণ করে — লিস্টে এখন শুধু [10, 30] থাকে, last এর মান হয় 40। কোনো আর্গুমেন্ট না দিলে pop() সবসময় শেষ উপাদান সরায়।
print(items, last) পরিবর্তিত items লিস্ট [10, 30] এবং last এর মান 40 দুটোই একসাথে প্রদর্শন করে — print() এর মধ্যে একাধিক মান কমা দিয়ে পাঠালে Python সেগুলোকে space দিয়ে আলাদা করে এক লাইনে দেখায়।
কেন কাজ করছে?
After append the list grows. remove deletes 20. pop returns the final item.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Nested lists

সহজ ভাষায়: A list can contain other lists, which is useful for tables and matrices.

Example

matrix = [[1, 2], [3, 4]]
print(matrix[1][0])

Line-by-line explanation

matrix = [[1, 2], [3, 4]] বাইরের একটি লিস্টের ভিতরে ২টি আলাদা লিস্ট রেখে 2x2 ম্যাট্রিক্স আকারের নেস্টেড লিস্ট (list inside list) তৈরি করে — matrix[0] = প্রথম সারি [1,2], matrix[1] = দ্বিতীয় সারি [3,4]।
print(matrix[1][0]) দ্বি-স্তরের indexing: প্রথমে matrix[1] দিয়ে বাইরের লিস্টের 1 নং index উপাদান বের করে = [3, 4] (দ্বিতীয় সারি), তারপর [0] দিয়ে ওই ভেতরের লিস্টের 0 নং index প্রথম উপাদান 3 প্রদর্শন করে।
কেন কাজ করছে?
matrix[1] selects the second row; [0] selects its first value.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. List comprehension

সহজ ভাষায়: A comprehension creates a new list from an iterable with optional filtering.

Example

numbers = [1,2,3,4,5]
squares = [n*n for n in numbers if n % 2 == 0]
print(squares)

Line-by-line explanation

numbers = [1,2,3,4,5] 1 থেকে 5 পর্যন্ত পূর্ণসংখ্যা নিয়ে numbers নামে একটি লিস্ট তৈরি করে।
squares = [n*n for n in numbers if n % 2 == 0] list comprehension দিয়ে নতুন লিস্ট তৈরি করে: for n in numbers দিয়ে numbers থেকে প্রতিটি n নেওয়া হয়, if n % 2 == 0 দিয়ে শুধু জোড় সংখ্যা (2, 4) ফিল্টার করা হয়, সবশেষে n*n করে তাদের বর্গ বের করে squares লিস্টে রাখা হয় → চূড়ান্ত squares = [4, 16]।
print(squares) উপরের list comprehension দিয়ে তৈরি squares লিস্ট [4, 16] প্রদর্শন করে।
কেন কাজ করছে?
Read it as: take n from numbers, keep even n, then calculate n*n.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
