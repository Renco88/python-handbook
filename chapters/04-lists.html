Lists

creation, indexing, slicing, methods, nested lists, copying, comprehensions

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. Creating a list

সহজ ভাষায়: Lists store multiple values in one ordered, mutable collection.

Example

fruits = ["apple", "banana", "mango"]
print(fruits[1])

Line-by-line explanation

fruits = ["apple", "banana", "mango"]
print(fruits[1])
কেন কাজ করছে?
The list has three elements. Index 1 points to banana.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. List methods

সহজ ভাষায়: append adds, insert places, remove deletes by value, and pop removes and returns an item.

Example

items = [10, 20, 30]
items.append(40)
items.remove(20)
last = items.pop()
print(items, last)

Line-by-line explanation

items = [10, 20, 30]
items.append(40)
items.remove(20)
last = items.pop()
print(items, last)
কেন কাজ করছে?
After append the list grows. remove deletes 20. pop returns the final item.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Nested lists

সহজ ভাষায়: A list can contain other lists, which is useful for tables and matrices.

Example

matrix = [[1, 2], [3, 4]]
print(matrix[1][0])

Line-by-line explanation

matrix = [[1, 2], [3, 4]]
print(matrix[1][0])
কেন কাজ করছে?
matrix[1] selects the second row; [0] selects its first value.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. List comprehension

সহজ ভাষায়: A comprehension creates a new list from an iterable with optional filtering.

Example

numbers = [1,2,3,4,5]
squares = [n*n for n in numbers if n % 2 == 0]
print(squares)

Line-by-line explanation

numbers = [1,2,3,4,5]
squares = [n*n for n in numbers if n % 2 == 0]
print(squares)
কেন কাজ করছে?
Read it as: take n from numbers, keep even n, then calculate n*n.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
