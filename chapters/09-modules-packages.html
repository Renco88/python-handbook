Modules & Packages

import, standard library, creating modules, packages, pip and virtual environments

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. Importing modules

সহজ ভাষায়: Modules let you reuse code from another file or the standard library.

Example

import math
print(math.sqrt(144))

Line-by-line explanation

import math
print(math.sqrt(144))
কেন কাজ করছে?
import loads the module; math.sqrt accesses its sqrt function.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Creating a module

সহজ ভাষায়: Your own .py file can be imported by another script.

Example

# tools.py
def double(x):
    return x * 2

# main.py
from tools import double
print(double(8))

Line-by-line explanation

# tools.py
def double(x):
return x * 2
# main.py
from tools import double
print(double(8))
কেন কাজ করছে?
The function lives in tools.py and is imported into main.py.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. pip and environments

সহজ ভাষায়: Virtual environments isolate project dependencies.

Example

python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
pip install requests

Line-by-line explanation

python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
pip install requests
কেন কাজ করছে?
The environment keeps packages for one project separate from others.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
