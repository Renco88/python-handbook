1. Array vs Python list

সহজ ভাষায়: NumPy arrays are designed for efficient numerical operations.

Example

import numpy as np
a=np.array([1,2,3])
print(a*2)

Line-by-line explanation

import numpy as npNumPy লাইব্রেরি লোড করে সংক্ষিপ্ত নাম 'np' হিসেবে বাইন্ড করা হয়েছে
a=np.array([1,2,3])Python list [1,2,3] থেকে ১D NumPy array তৈরি করে ভেরিয়েবল 'a'-এ সংরক্ষণ করা হয়েছে
print(a*2)Vectorized multiplication: array 'a'-র প্রতিটি উপাদানকে ২ দ্বারা গুণ করে প্রিন্ট করা হয়েছে
কেন কাজ করছে?
The multiplication is vectorized: each element is multiplied by 2.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Indexing and slicing

সহজ ভাষায়: NumPy supports multidimensional indexing and slicing.

Example

a=np.arange(12).reshape(3,4)
print(a[1,2])
print(a[:,1])

Line-by-line explanation

a=np.arange(12).reshape(3,4)০-১১ পর্যন্ত সংখ্যার ১D array তৈরি করে ৩x৪ মাত্রার ২D matrix-এ রূপান্তরিত করা হয়েছে
print(a[1,2])২D array-এর ২য় সারি (index ১) ও ৩য় কলাম (index ২) এর উপাদান প্রিন্ট করা হয়েছে
print(a[:,1])সব সারি থেকে শুধু ২য় কলাম (index ১) এর সকল উপাদান একত্রে প্রিন্ট করা হয়েছে
কেন কাজ করছে?
a[1,2] selects row 1, column 2; : selects all rows.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Aggregation

সহজ ভাষায়: Functions such as mean, sum, min and max summarize arrays.

Example

a=np.array([10,20,30,40])
print(a.mean(), a.sum(), a.max())

Line-by-line explanation

a=np.array([10,20,30,40])[10,20,30,40] মান দিয়ে একটি নতুন ১D NumPy array তৈরি করা হয়েছে
print(a.mean(), a.sum(), a.max())array-এর গড় মান, মোট যোগফল ও সর্বোচ্চ মান একসাথে প্রিন্ট করা হয়েছে
কেন কাজ করছে?
Aggregation reduces many values to useful summary statistics.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Masks

সহজ ভাষায়: Boolean masks select values matching a condition.

Example

a=np.array([10,15,20,25])
print(a[a >= 20])

Line-by-line explanation

a=np.array([10,15,20,25])[10,15,20,25] মানসমূহ দিয়ে ১D NumPy array তৈরি করা হয়েছে
print(a[a >= 20])Boolean mask দিয়ে ২০ বা তার বেশি মানবিশিষ্ট উপাদানগুলোকে ফিল্টার করে প্রিন্ট করা হয়েছে
কেন কাজ করছে?
The comparison creates a Boolean array, then the mask filters the data.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
