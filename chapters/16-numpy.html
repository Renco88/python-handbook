NumPy

arrays, dtypes, indexing, vectorized operations, aggregation, broadcasting, masks and sorting

1. Array vs Python list

সহজ ভাষায়: NumPy arrays are designed for efficient numerical operations.

Example

import numpy as np
a=np.array([1,2,3])
print(a*2)

Line-by-line explanation

import numpy as np
a=np.array([1,2,3])
print(a*2)
কেন কাজ করছে?
The multiplication is vectorized: each element is multiplied by 2.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Indexing and slicing

সহজ ভাষায়: NumPy supports multidimensional indexing and slicing.

Example

a=np.arange(12).reshape(3,4)
print(a[1,2])
print(a[:,1])

Line-by-line explanation

a=np.arange(12).reshape(3,4)
print(a[1,2])
print(a[:,1])
কেন কাজ করছে?
a[1,2] selects row 1, column 2; : selects all rows.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Aggregation

সহজ ভাষায়: Functions such as mean, sum, min and max summarize arrays.

Example

a=np.array([10,20,30,40])
print(a.mean(), a.sum(), a.max())

Line-by-line explanation

a=np.array([10,20,30,40])
print(a.mean(), a.sum(), a.max())
কেন কাজ করছে?
Aggregation reduces many values to useful summary statistics.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Masks

সহজ ভাষায়: Boolean masks select values matching a condition.

Example

a=np.array([10,15,20,25])
print(a[a >= 20])

Line-by-line explanation

a=np.array([10,15,20,25])
print(a[a >= 20])
কেন কাজ করছে?
The comparison creates a Boolean array, then the mask filters the data.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
