HTTP, APIs & Automation

requests, HTTP concepts, JSON APIs, status codes, automation patterns and safe scripting

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. HTTP mental model

সহজ ভাষায়: A client sends a request; a server returns a response with a status code and data.

Example

import requests
r=requests.get("https://api.github.com", timeout=10)
print(r.status_code)

Line-by-line explanation

import requests
r=requests.get("https://api.github.com", timeout=10)
print(r.status_code)
কেন কাজ করছে?
requests performs the HTTP call and status_code tells you the outcome class.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. JSON API

সহজ ভাষায়: Many APIs return JSON that becomes Python dictionaries/lists.

Example

data=r.json()
print(type(data))
print(data.keys())

Line-by-line explanation

data=r.json()
print(type(data))
print(data.keys())
কেন কাজ করছে?
json() parses the response body into Python data.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. POST request

সহজ ভাষায়: POST commonly sends data to a server.

Example

payload={"name":"Renco"}
r=requests.post("https://httpbin.org/post", json=payload, timeout=10)
print(r.status_code)

Line-by-line explanation

payload={"name":"Renco"}
r=requests.post("https://httpbin.org/post", json=payload, timeout=10)
print(r.status_code)
কেন কাজ করছে?
The json parameter serializes the dictionary as JSON.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Automation

সহজ ভাষায়: Automation means turning a repeated manual workflow into deterministic code.

Example

from pathlib import Path
for p in Path(".").glob("*.txt"):
    print("Found:",p.name)

Line-by-line explanation

from pathlib import Path
for p in Path(".").glob("*.txt"):
print("Found:",p.name)
কেন কাজ করছে?
The script discovers matching files without manually listing them.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
