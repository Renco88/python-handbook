1. Unpacking

সহজ ভাষায়: Python can unpack sequences into separate variables.

Example

first, *middle, last = [1,2,3,4]
print(first, middle, last)

Line-by-line explanation

first, *middle, last = [1,2,3,4]
print(first, middle, last)
কেন কাজ করছে?
The star collects remaining values into a list.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Generator

সহজ ভাষায়: Generators produce values lazily with yield.

Example

def countdown(n):
    while n:
        yield n
        n -= 1
print(list(countdown(3)))

Line-by-line explanation

def countdown(n):
while n:
yield n
n -= 1
print(list(countdown(3)))
কেন কাজ করছে?
yield pauses the function and resumes it later, which can save memory.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Decorator

সহজ ভাষায়: A decorator wraps a function to add behavior.

Example

def log_call(fn):
    def wrapper(*args, **kwargs):
        print("Calling", fn.__name__)
        return fn(*args, **kwargs)
    return wrapper

@log_call
def hello(): return "Hi"
print(hello())

Line-by-line explanation

def log_call(fn):
def wrapper(*args, **kwargs):
print("Calling", fn.__name__)
return fn(*args, **kwargs)
return wrapper
@log_call
def hello(): return "Hi"
print(hello())
কেন কাজ করছে?
@log_call replaces hello with the wrapped version.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Context manager

সহজ ভাষায়: with is a clean way to acquire and release resources.

Example

with open("notes.txt", encoding="utf-8") as f:
    text=f.read()

Line-by-line explanation

with open("notes.txt", encoding="utf-8") as f:
text=f.read()
কেন কাজ করছে?
The context manager handles cleanup automatically.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
