Portfolio Projects

CLI app, automation tool, API client, data dashboard and capstone project architecture

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. CLI project

সহজ ভাষায়: A command-line application can combine functions, files, validation and menus.

Example

def add(a,b): return a+b
print(add(10,20))

Line-by-line explanation

def add(a,b): return a+b"add" নামে helper function ডিফাইন করা হয়েছে যা a ও b দুইটি numeric parameter গ্রহণ করে এবং তাদের যোগফল সরাসরি return করে — ছোট mathematical operation-এর জন্য compact inline return ব্যবহৃত হয়েছে
print(add(10,20))add() ফাংশনকে arguments a=10 ও b=20 দিয়ে call করলে return value 30 আসে; সেই integer result কে কনসোলে print করে প্রদর্শন করা হয়েছে — এইভাবে ছোট functions গুলো CLI menu থেকে ব্যবহার করা যায়
কেন কাজ করছে?
Start with small functions and then connect them through a menu or argparse.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Automation project

সহজ ভাষায়: A useful automation project detects files and performs a repeatable transformation.

Example

from pathlib import Path
for p in Path(".").glob("*.txt"):
    print(p.name)

Line-by-line explanation

from pathlib import PathPython-এর modern pathlib মডিউল থেকে Path ক্লাস import করা হয়েছে — এটি OOP ভিত্তিক file/folder path manipulation করতে পারে; legacy os.path মডিউলের তুলনায় এটি আরো পরিষ্কার ও readable
for p in Path(".").glob("*.txt"):Path(".") = current working directory (যেখান থেকে script চালানো হয়েছে); glob("*.txt") wildcard pattern match করে current dir-এর সব .txt extension ফাইল খুঁজে বের করে; সেই প্রতিটি ফাইলের Path object p হিসেবে for loop iterate করবে
print(p.name)প্রতিটি txt ফাইলের শুধু ফাইলের নাম (p.name attribute) কনসোলে print করা হয়; p.name = filename only (full path না), p.parent = parent directory, p.suffix = extension, p.stem = name without extension — এগুলো দিয়ে rename/copy/move বাকি automation step লেখা যায়
কেন কাজ করছে?
Add validation, logging and a dry-run mode before using automation on important data.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. API project

সহজ ভাষায়: An API client combines HTTP, JSON, errors and configuration.

Example

import requests
r=requests.get("https://api.github.com",timeout=10)
r.raise_for_status()
print(r.json())

Line-by-line explanation

import requestsPython-এর সবচেয়ে জনপ্রিয় third-party HTTP client library "requests" লোড করা হয়েছে — GET/POST/PUT/DELETE REST API call করতে, header/query parameter সহজে handle করতে এটি standard ব্যবহৃত হয়
r=requests.get("https://api.github.com",timeout=10)GitHub-এর public root API endpoint (https://api.github.com) -এ HTTP GET request পাঠানো হয়েছে; timeout=10 সেট করা হয়েছে যাতে server না reply করলে ১০ সেকেন্ডের পর socket timeout হয়ে request hang না করে
r.raise_for_status()HTTP response status code check করা হয় — যদি ৪xx (client error, যেমন: 404 Not Found) অথবা 5xx (server error, যেমন: 500 Internal) হয় তাহলে HTTPError exception raise করবে; এটি error handling-র সহজ standard pattern (silent failure এড়ানো যায়)
print(r.json())Response object r-এর body যেটি JSON format-এ আছে — r.json() method দিয়ে সেই JSON string-কে automatically Python dictionary/list (nested structure) -এ parse করা হয় এবং parsed data কনসোলে pretty print হয়
কেন কাজ করছে?
raise_for_status turns unsuccessful HTTP responses into exceptions.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Capstone architecture

সহজ ভাষায়: A portfolio project should have a clear separation between interface, business logic and data access.

Example

project/
  app/
    main.py
    services.py
    storage.py
  tests/
  README.md

Line-by-line explanation

project/Portfolio project-এর root / parent directory — সম্পূর্ণ project-এর সব files/folders এই folder-এর ভিতরে থাকে; GitHub repo-র top-level folderও এটিই হয়
app/"app" নামের main source code subfolder — এখানে সব application business source code থাকে; library import সহজ করার জন্য package হিসেবে treat করা হয় (সাধারণত __init__.py থাকে)
main.pyApplication-এর entry point / main execution file — CLI menu parsing (argparse/click), Flask/FastAPI routes instantiation, web server start সব initialization এখানে থাকে; business logic এখানে সরাসরি লেখা উচিত না
services.pyBusiness logic layer — সব core feature logic, calculation, rules, transformations এখানে থাকে; input/output interface বা data storage থেকে fully decoupled থাকে তাই unit test করা সহজ হয় — clean architecture-এর heart
storage.pyData access layer — database CRUD operations, file I/O, external API credentials management, cache interface — সব data persistence logic এখানে encapsulated থাকে; services এখান থেকে function call করে data ব্যবহার করে
tests/Automated unit/integration test files separate folder — pytest বা unittest test runner এই folder-এর সব test_*.py files run করবে; main source থেকে আলাদা থাকায় packaging-এ সময় test files include হয় না
README.mdProject documentation file (Markdown format): install instructions, run commands, architecture explanation, feature list, screenshots, author info — সব portfolio project-এর জন্য এটি must have; interviewer প্রথমে এটিই দেখে
কেন কাজ করছে?
Separation makes the project easier to test, explain and extend.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
