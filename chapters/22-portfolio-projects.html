Portfolio Projects

CLI app, automation tool, API client, data dashboard and capstone project architecture

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. CLI project

সহজ ভাষায়: A command-line application can combine functions, files, validation and menus.

Example

def add(a,b): return a+b
print(add(10,20))

Line-by-line explanation

def add(a,b): return a+b
print(add(10,20))
কেন কাজ করছে?
Start with small functions and then connect them through a menu or argparse.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Automation project

সহজ ভাষায়: A useful automation project detects files and performs a repeatable transformation.

Example

from pathlib import Path
for p in Path(".").glob("*.txt"):
    print(p.name)

Line-by-line explanation

from pathlib import Path
for p in Path(".").glob("*.txt"):
print(p.name)
কেন কাজ করছে?
Add validation, logging and a dry-run mode before using automation on important data.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. API project

সহজ ভাষায়: An API client combines HTTP, JSON, errors and configuration.

Example

import requests
r=requests.get("https://api.github.com",timeout=10)
r.raise_for_status()
print(r.json())

Line-by-line explanation

import requests
r=requests.get("https://api.github.com",timeout=10)
r.raise_for_status()
print(r.json())
কেন কাজ করছে?
raise_for_status turns unsuccessful HTTP responses into exceptions.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Capstone architecture

সহজ ভাষায়: A portfolio project should have a clear separation between interface, business logic and data access.

Example

project/
  app/
    main.py
    services.py
    storage.py
  tests/
  README.md

Line-by-line explanation

project/
app/
main.py
services.py
storage.py
tests/
README.md
কেন কাজ করছে?
Separation makes the project easier to test, explain and extend.
