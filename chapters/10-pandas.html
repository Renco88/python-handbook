Chapter 10

Pandas

DataFrames, cleaning, filtering and analysis.

What you will learn

  • Build a clear mental model of the topic.
  • Read and explain small Python programs.
  • Practice by modifying examples instead of copying them.
  • Apply the idea in a small challenge.
Study loop: Concept → Example → Experiment → Practice → Challenge → Project

Core idea

Start with the smallest useful example. Run it, change one thing at a time, and predict the result before executing it. This makes the syntax memorable because every line has a purpose.

Worked example

import pandas as pd
df = pd.DataFrame({"name":["A","B","C"],"score":[70,92,85]})
print(df[df["score"] >= 80])

Try it yourself

  1. Run the example in Colab.
  2. Change at least two values and predict the output.
  3. Add one new requirement of your own.
  4. Rewrite the solution from memory.

Challenge
