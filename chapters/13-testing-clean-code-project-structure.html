Testing, Clean Code & Project Structure

Write maintainable Python with tests, assertions, naming, formatting, documentation, logging and sensible project structure.

1. The idea — বুঝে শেখা

Write maintainable Python with tests, assertions, naming, formatting, documentation, logging and sensible project structure. Python শেখার সময় শুধু syntax মুখস্থ না করে “এই code কেন লিখছি?”—এই প্রশ্নটা করা সবচেয়ে গুরুত্বপূর্ণ। Official Python documentation-এ tutorial, language reference, built-ins এবং standard library আলাদা করে সাজানো আছে; এই বই সেই concepts-কে beginner-friendly learning path-এ সাজায়। citeturn0search1turn0search3

Learning rule: প্রতিটি example নিজে টাইপ করো → output দেখো → একটি জিনিস পরিবর্তন করো → আবার run করো। এভাবেই syntax থেকে programming sense তৈরি হয়।

2. Simple test

def add(a, b):
    return a + b

assert add(2, 3) == 5

কী হচ্ছে? প্রথমে code-টি run করো। তারপর একটি variable/value বদলে দেখো output কীভাবে বদলায়। এই ছোট experiment-টাই concept বুঝে ফেলার সবচেয়ে সহজ উপায়।

Common mistakes

  • Indentation বা block structure ভুল করা। Python-এ indentation syntax-এর অংশ।
  • Variable-এর value আর variable-এর নামকে একই জিনিস ভাবা।
  • একসাথে অনেক নতুন concept মুখস্থ করা—বরং একটি concept নিয়ে ৫–১০টি ছোট example করো।
  • Error দেখলে code বাদ দেওয়া—traceback পড়ো, কোন line-এ সমস্যা সেটি আগে খুঁজে বের করো।

Practice zone

Challenge 1: নিজের একটি ছোট program লেখো যা user-এর input নেয় এবং meaningful output দেয়।

Challenge 2: উপরের একটি example copy না করে memory থেকে আবার লেখো।

Challenge 3: একটি edge case বের করো—যেমন empty input, zero, negative number বা duplicate data—এবং program-টি handle করো।
