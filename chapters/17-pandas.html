1. DataFrame

সহজ ভাষায়: A DataFrame is a labeled two-dimensional table.

Example

import pandas as pd
df=pd.DataFrame({"name":["A","B"],"score":[80,90]})
print(df)

Line-by-line explanation

import pandas as pd
df=pd.DataFrame({"name":["A","B"],"score":[80,90]})
print(df)
কেন কাজ করছে?
Each dictionary key becomes a column.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Selection

সহজ ভাষায়: Use column names and boolean masks to select data.

Example

print(df["score"])
print(df[df["score"] >= 85])

Line-by-line explanation

print(df["score"])
print(df[df["score"] >= 85])
কেন কাজ করছে?
The second line keeps rows whose score is at least 85.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. GroupBy

সহজ ভাষায়: groupby lets you calculate summaries by category.

Example

df=pd.DataFrame({"dept":["CSE","CSE","EEE"],"score":[80,90,70]})
print(df.groupby("dept")["score"].mean())

Line-by-line explanation

df=pd.DataFrame({"dept":["CSE","CSE","EEE"],"score":[80,90,70]})
print(df.groupby("dept")["score"].mean())
কেন কাজ করছে?
The data is split by dept, then mean is calculated for each group.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Missing data

সহজ ভাষায়: Real datasets often contain missing values that need explicit handling.

Example

df=df.fillna(0)
print(df)

Line-by-line explanation

df=df.fillna(0)
print(df)
কেন কাজ করছে?
fillna replaces missing values; the right choice depends on the meaning of the missing data.
