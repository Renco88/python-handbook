Loops

for, while, range, enumerate, zip, break, continue, pass and nested loops

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. for loop

সহজ ভাষায়: for repeats a block for each item in an iterable.

Example

for name in ["A", "B", "C"]:
    print(name)

Line-by-line explanation

for name in ["A", "B", "C"]:
print(name)
কেন কাজ করছে?
Python takes each element in order and assigns it to name.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. range()

সহজ ভাষায়: range generates a sequence of numbers without creating a large list.

Example

for i in range(1, 6):
    print(i)

Line-by-line explanation

for i in range(1, 6):
print(i)
কেন কাজ করছে?
The start is 1 and the stop is 6, but 6 is excluded.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. enumerate() and zip()

সহজ ভাষায়: enumerate gives an index; zip walks through multiple sequences together.

Example

names=["A","B"]
scores=[80,90]
for i,(name,score) in enumerate(zip(names,scores), start=1):
    print(i,name,score)

Line-by-line explanation

names=["A","B"]
scores=[80,90]
for i,(name,score) in enumerate(zip(names,scores), start=1):
print(i,name,score)
কেন কাজ করছে?
zip pairs corresponding values; enumerate adds a counter.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. break and continue

সহজ ভাষায়: break stops a loop; continue skips the current iteration.

Example

for n in range(1,6):
    if n == 3:
        continue
    if n == 5:
        break
    print(n)

Line-by-line explanation

for n in range(1,6):
if n == 3:
continue
if n == 5:
break
print(n)
কেন কাজ করছে?
3 is skipped; when 5 is reached the loop ends.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
