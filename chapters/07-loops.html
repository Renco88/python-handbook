Loops

for, while, range, enumerate, zip, break, continue, pass and nested loops

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. for loop

সহজ ভাষায়: for repeats a block for each item in an iterable.

Example

for name in ["A", "B", "C"]:
    print(name)

Line-by-line explanation

for name in ["A", "B", "C"]: for লুপ: লিস্ট ["A", "B", "C"]-এর প্রতিটি উপাদান আলাদাভাবে ধরবে — প্রথম ইটারেশনে name = "A", দ্বিতীয়বার "B", তৃতীয়বার "C" হবে এবং প্রতিবারই লুপের নিচে ইন্ডেন্টেড ব্লকটি কার্যকর হবে। লাইনের শেষে কোলন : দিতে হবে।
print(name) লুপের ব্লকের একমাত্র লাইন — প্রতি ইটারেশনে name-এ যে মান বর্তমানে আছে সেটি আলাদা আলাদা লাইনে প্রদর্শন করে। ফলে লিস্টের উপাদানগুলো এভাবে প্রিন্ট হবে: প্রথমে A, তারপর B, সবশেষে C।
কেন কাজ করছে?
Python takes each element in order and assigns it to name.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. range()

সহজ ভাষায়: range generates a sequence of numbers without creating a large list.

Example

for i in range(1, 6):
    print(i)

Line-by-line explanation

for i in range(1, 6): range(start, stop) গাণিতিক অন্তরালের মতোই [1, 6) অর্থাৎ 1 থেকে শুরু করে 5 পর্যন্ত ধাপে ধাপে সংখ্যা তৈরি করে (6 সবসময় বাদ দেওয়া হয়)। তাই i এর মান ক্রমানুসারে হবে 1, 2, 3, 4, 5 এবং প্রতিটি মানের জন্য লুপের ব্লক একবার করে চলবে।
print(i) প্রতি ইটারেশনে i-এর বর্তমান সংখ্যাটি প্রদর্শন করে — চূড়ান্ত আউটপুট হবে 1 থেকে 5 পর্যন্ত প্রতিটি সংখ্যা নিজের আলাদা লাইনে।
কেন কাজ করছে?
The start is 1 and the stop is 6, but 6 is excluded.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. enumerate() and zip()

সহজ ভাষায়: enumerate gives an index; zip walks through multiple sequences together.

Example

names=["A","B"]
scores=[80,90]
for i,(name,score) in enumerate(zip(names,scores), start=1):
    print(i,name,score)

Line-by-line explanation

names=["A","B"] দুটি ছাত্রের নাম নিয়ে names নামে একটি লিস্ট তৈরি করে — পরবর্তীতে scores লিস্টের সাথে মিলিয়ে ব্যবহার হবে।
scores=[80,90] উপরের ছাত্রদের নামের সাথে একই ক্রম (corresponding) তাদের নম্বর নিয়ে আরেকটি লিস্ট scores তৈরি করে — প্রথম ছাত্রের নম্বর 80, দ্বিতীয়টি 90।
for i,(name,score) in enumerate(zip(names,scores), start=1): zip(names, scores) দুটি লিস্টকে সারি সারি মিলিয়ে জোড়া দেয়: প্রথম জোড়া ("A", 80), দ্বিতীয় জোড়া ("B", 90) → এরপর enumerate(start=1) প্রতিটি জোড়ার সাথে 1 থেকে শুরু করে একটি কাউন্টার/সিরিয়াল সংযুক্ত করে → চূড়ান্ত for লুপে i হলো সিরিয়াল, আর (name, score) হলো জোড়া থেকে আলাদা আলাদা ভেরিয়েবলে আনপ্যাক করা মান।
print(i,name,score) লুপের প্রতি ধাপে i (সিরিয়াল নম্বর), name (নাম) ও score (নম্বর) দেখায় — চূড়ান্ত আউটপুট হবে প্রথম লাইন "1 A 80", দ্বিতীয় লাইন "2 B 90"।
কেন কাজ করছে?
zip pairs corresponding values; enumerate adds a counter.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. break and continue

সহজ ভাষায়: break stops a loop; continue skips the current iteration.

Example

for n in range(1,6):
    if n == 3:
        continue
    if n == 5:
        break
    print(n)

Line-by-line explanation

for n in range(1,6): 1 থেকে 5 পর্যন্ত সংখ্যা নিয়ে লুপ শুরু করে — n এর মান ক্রমানুসারে হবে 1, 2, 3, 4, 5।
if n == 3: লুপের ভিতরে প্রথম শর্ত: n এর মান ঠিক 3 কিনা? n=3 হলে শর্তটি সত্য হবে।
continue continue মানে: বর্তমান এই ইটারেশনের বাকি সব কাজ এখনই বাদ দিয়ে সরাসরি লুপের পরের ধাপ (next iteration) এ চলে যাও — তাই n=3 হলে এরপরের কোনো লাইনই এই ধাপে আর চলবে না, 3 কখনো প্রিন্ট হবে না।
if n == 5: লুপের ভিতরে দ্বিতীয় শর্ত: n এর মান ঠিক 5 কিনা? (কেবলমাত্র যদি আগের continue দিয়ে না বের হয়ে এসে)।
break break মানে: লুপটিকে এখনই পুরোপুরি ভেঙ্গে বের হয়ে যাও — আর কোনো পরবর্তী ইটারেশন হবে না। তাই n=5 হলে লুপ সেখানেই থেমে যাবে; পরের লাইন print এ যাবে না বলে 5 কখনো প্রিন্ট হবে না।
print(n) যদি কোনো continue বা break না হয়ে এসে থাকে তাহলে n প্রিন্ট হবে। ট্রেস: n=1→কোনো শর্ত না→প্রিন্ট (1); n=2→প্রিন্ট (2); n=3→প্রথম if সত্য→continue→প্রিন্ট না; n=4→প্রিন্ট (4); n=5→দ্বিতীয় if সত্য→break→লুপ থামে→প্রিন্ট না। তাই চূড়ান্ত আউটপুট শুধু 1, 2, 4 মাত্র।
কেন কাজ করছে?
3 is skipped; when 5 is reached the loop ends.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
