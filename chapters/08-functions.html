Functions

parameters, return, defaults, keyword arguments, scope, *args, **kwargs, lambda, recursion

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. Defining a function

সহজ ভাষায়: Functions package reusable behavior.

Example

def add(a, b):
    return a + b

print(add(10, 20))

Line-by-line explanation

def add(a, b):
return a + b
print(add(10, 20))
কেন কাজ করছে?
def creates the function. Parameters receive values. return sends a result back.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Default and keyword arguments

সহজ ভাষায়: Defaults make arguments optional and keyword arguments make calls clearer.

Example

def greet(name, message="Welcome"):
    return f"{message}, {name}!"
print(greet("Renco"))
print(greet("Renco", message="Good morning"))

Line-by-line explanation

def greet(name, message="Welcome"):
return f"{message}, {name}!"
print(greet("Renco"))
print(greet("Renco", message="Good morning"))
কেন কাজ করছে?
The default is used when message is omitted. The keyword call explicitly names the parameter.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. *args and **kwargs

সহজ ভাষায়: They collect variable-length positional and keyword arguments.

Example

def report(*scores, **info):
    print(scores)
    print(info)
report(80,90,name="Renco")

Line-by-line explanation

def report(*scores, **info):
print(scores)
print(info)
report(80,90,name="Renco")
কেন কাজ করছে?
scores becomes a tuple; info becomes a dictionary.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Recursion

সহজ ভাষায়: A recursive function calls itself and needs a base case.

Example

def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n-1)
print(factorial(5))

Line-by-line explanation

def factorial(n):
if n <= 1:
return 1
return n * factorial(n-1)
print(factorial(5))
কেন কাজ করছে?
The base case stops recursion. Each call reduces n until the base case.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
