Tuples, Sets & Dictionaries

immutable sequences, unique collections, key-value data, methods and practical records

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. Tuple

সহজ ভাষায়: A tuple is an ordered collection that cannot be changed after creation.

Example

point = (10, 20)
x, y = point
print(x, y)

Line-by-line explanation

point = (10, 20)
x, y = point
print(x, y)
কেন কাজ করছে?
Tuple unpacking assigns the first value to x and the second to y.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Set

সহজ ভাষায়: A set stores unique values and is useful for membership and set operations.

Example

values = {1,2,2,3}
print(values)
print({1,2} & {2,3})

Line-by-line explanation

values = {1,2,2,3}
print(values)
print({1,2} & {2,3})
কেন কাজ করছে?
Duplicates disappear. & returns the intersection.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Dictionary

সহজ ভাষায়: A dictionary maps keys to values.

Example

student = {"name":"Renco", "score":90}
print(student["name"])
student["score"] = 95

Line-by-line explanation

student = {"name":"Renco", "score":90}
print(student["name"])
student["score"] = 95
কেন কাজ করছে?
Keys identify values. Assignment updates an existing key.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Safe dictionary access

সহজ ভাষায়: get() can provide a default instead of raising a KeyError.

Example

email = student.get("email", "Not provided")
print(email)

Line-by-line explanation

email = student.get("email", "Not provided")
print(email)
কেন কাজ করছে?
If email does not exist, get returns the fallback text.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
