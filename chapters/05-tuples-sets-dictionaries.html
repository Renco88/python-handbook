Tuples, Sets & Dictionaries

immutable sequences, unique collections, key-value data, methods and practical records

How to study this page: প্রথমে explanation পড়ো → code নিজে টাইপ করো → output দেখো → প্রতিটি line কী করছে নিজের ভাষায় বলো → তারপর code পরিবর্তন করো।

1. Tuple

সহজ ভাষায়: A tuple is an ordered collection that cannot be changed after creation.

Example

point = (10, 20)
x, y = point
print(x, y)

Line-by-line explanation

point = (10, 20) দুটি পূর্ণসংখ্যা 10, 20 নিয়ে একটি টাপল (tuple) তৈরি করে point ভেরিয়েবলে রাখে — টাপল first bracket ( ) দিয়ে তৈরি হয়, এটি immutable অর্থাৎ একবার তৈরি হয়ে গেলে কোনো উপাদান যোগ-বাদলা-মুছে ফেলা যায় না।
x, y = point tuple unpacking: point টাপলের প্রথম মান 10 কে x ভেরিয়েবলে ও দ্বিতীয় মান 20 কে y ভেরিয়েবলে এক লাইনে অ্যাসাইন করে — বামদিকে যতগুলো ভেরিয়েবল কমা দিয়ে থাকে, ডানদিকের টাপল/লিস্টে ততগুলো উপাদান থাকতে হবে।
print(x, y) x ও y এর বর্তমান মান 10 20 কে একটি স্পেস দিয়ে আলাদা করে এক লাইনে প্রদর্শন করে।
কেন কাজ করছে?
Tuple unpacking assigns the first value to x and the second to y.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

2. Set

সহজ ভাষায়: A set stores unique values and is useful for membership and set operations.

Example

values = {1,2,2,3}
print(values)
print({1,2} & {2,3})

Line-by-line explanation

values = {1,2,2,3} curly brace { } দিয়ে একটি সেট তৈরি করে — সেটের প্রধান বৈশিষ্ট্য ডুপ্লিকেট মান রাখা যায় না, তাই লেখার সময় 2 দুইবার দেওয়া হলেও Python স্বয়ংক্রিয়ভাবে একটি রাখে বাকিটি সরিয়ে দেয়; চূড়ান্ত values = {1, 2, 3} (order নিশ্চিত নয়)।
print(values) উপরের সেটের উপাদানগুলো {1, 2, 3} আকারে প্রদর্শন করে — ডুপ্লিকেট 2 আর থাকছে না, প্রমাণ যে সেট ইউনিক মানই রাখে।
print({1,2} & {2,3}) দুটি সেটের ইন্টারসেকশন (intersection / সাধারণ উপাদান) বের করে — & অপারেটরটি দুটি সেটের যে সকল মান উভয় সেটেই সাধারণভাবে আছে শুধু সেগুলোই নিয়ে নতুন সেট {2} প্রদর্শন করে (2 দুটি সেটেই আছে)।
কেন কাজ করছে?
Duplicates disappear. & returns the intersection.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

3. Dictionary

সহজ ভাষায়: A dictionary maps keys to values.

Example

student = {"name":"Renco", "score":90}
print(student["name"])
student["score"] = 95

Line-by-line explanation

student = {"name":"Renco", "score":90} দুটি key-value pair নিয়ে একটি ডিকশনারি (dictionary) তৈরি করে — {key: value} ফরম্যাটে লেখা হয়: "name" key = "Renco" value, "score" key = 90 value। key দিয়ে value খুঁজে পাওয়া যায়।
print(student["name"]) student ডিকশনারিতে key "name" এর value "Renco" বের করে প্রদর্শন করে — dict[key] দিয়ে ঠিক key অনুযায়ী value অ্যাক্সেস করা হয়, এখানে key হিসেবে স্ট্রিং "name" ব্যবহার করা হয়েছে।
student["score"] = 95 student ডিকশনারিতে "score" key আছেই, তাই নতুন মান 95 অ্যাসাইন করলে পুরোনো value 90 এর বদলে 95 হয়ে যায় — এভাবে ডিকশনারির মান পরিবর্তন (আপডেট) করা যায়; নতুন key দিলে নতুন entry যোগ হয়।
কেন কাজ করছে?
Keys identify values. Assignment updates an existing key.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।

4. Safe dictionary access

সহজ ভাষায়: get() can provide a default instead of raising a KeyError.

Example

email = student.get("email", "Not provided")
print(email)

Line-by-line explanation

email = student.get("email", "Not provided") get() মেথড প্রথম আর্গুমেন্ট "email" key এর জন্য student ডিকশনারি অনুসন্ধান করে — "email" key আছে না তাই সাধারণ dict["email"] দিলে KeyError হতো, কিন্তু get() দ্বিতীয় আর্গুমেন্ট হিসেবে দেওয়া ডিফল্ট মান "Not provided" রিটার্ন করে এবং তা email এ যায়। যদি key থাকতো তাহলে ওই value রিটার্ন করতো।
print(email) উপরে get() থেকে পাওয়া মান "Not provided" কনসোলে প্রদর্শন করে — এভাবে সেফভাবে key missing হ্যান্ডেল করা Python-এ শ্রেষ্ঠ অভ্যাস।
কেন কাজ করছে?
If email does not exist, get returns the fallback text.
নিজে experiment করো: উপরের example-এ অন্তত ২টি value পরিবর্তন করে output আগে অনুমান করো, তারপর run করো।
