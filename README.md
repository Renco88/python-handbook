# Python Handbook — Ready to Deploy

A polished static, book-style Python handbook for GitHub Pages.

## Deploy

1. Upload/replace the repository contents with this folder.
2. Keep the repository name `python-handbook`.
3. Enable GitHub Pages from **Settings → Pages → Deploy from branch → main / root**.
4. The site will be available at `https://renco88.github.io/python-handbook/`.

## Important: Colab

Every chapter contains `notebooks/<chapter>/lesson.ipynb`, and each chapter's **Open in Colab** button points to the matching GitHub notebook path.

## Local

Open `index.html` directly or serve the folder with any static server. No build step or npm dependency is required.
