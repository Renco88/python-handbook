# Python Handbook — Professional Edition

A static, beginner-friendly Python book.

## Structure
Every chapter follows:
1. Concept in simple language
2. Separate example for each topic
3. Full code
4. Line-by-line explanation
5. Experiment prompt
6. Practice Lab
7. Colab notebook

## Deployment
```bash
git add .
git commit -m "Build professional Python handbook"
git push
```
Enable GitHub Pages from `main` / root.

## Colab
The buttons are configured for `renco88/python-handbook` on the `main` branch.
