# 🐍 Python Handbook — Basic to Advanced

A practical, notebook-first Python learning handbook for students who want to go from **zero to confident Python**, then move naturally toward **NumPy, Pandas, visualization, data science, AI/ML, and research**.

## 🎯 Why this repository?

University courses often introduce Python through individual topics. This repository turns those topics into a structured learning path:

```text
Python Basics
    ↓
Control Flow
    ↓
Data Structures
    ↓
Functions
    ↓
Files + Errors + Modules
    ↓
OOP
    ↓
Intermediate Python
    ↓
NumPy
    ↓
Pandas
    ↓
Visualization
    ↓
Projects
    ↓
Data Science / AI / ML
```

## 📚 How the repository is organized

Each topic has its own folder. Open a folder, read its README, then open the notebook and practice in Google Colab.

| Folder | Topic |
|---|---|
| `00-start-here` | How to use the handbook |
| `01-python-fundamentals` | Syntax, variables, data types |
| `02-control-flow` | Conditions and loops |
| `03-data-structures` | Lists, tuples, sets, dictionaries |
| `04-functions` | Functions and reusable code |
| `05-files-errors-modules` | Files, JSON, CSV, exceptions, imports |
| `06-object-oriented-python` | Classes and OOP |
| `07-python-intermediate` | Comprehensions, generators, decorators |
| `08-python-for-data` | Data-oriented Python |
| `09-numpy` | Numerical computing |
| `10-pandas` | Data analysis |
| `11-visualization` | Matplotlib and visual communication |
| `12-projects` | Practical projects and capstone |

## ☁️ Google Colab

The notebooks are designed to run in Google Colab.

Open a chapter → open `lesson.ipynb` → **Open in Colab** → run the cells → modify the examples → complete the challenges.

## 🧠 Learning philosophy

This is not meant to be a collection of code to copy.

Every chapter follows:

**Concept → Example → Experiment → Practice → Challenge → Project**

The goal is to understand *why* the code works and eventually write it independently.

## 🎓 Suitable for students

This handbook is especially useful for students taking an introductory Python course, including students from **BBA, CSE, science, business analytics, and other disciplines**.

No advanced programming background is required.

## 🚀 Roadmap

### Beginner
Python syntax → variables → data types → strings → operators → conditions → loops

### Core Python
Lists → tuples → sets → dictionaries → functions → files → exceptions → modules

### Strong Python
OOP → comprehensions → iterators → generators → decorators → type hints

### Data Python
NumPy → Pandas → Matplotlib → data cleaning → exploratory analysis

### Build
Mini projects → portfolio data → capstone projects

## ⭐ Golden Rule

> **Don't just read Python. Run it, change it, break it, fix it, and build with it.**

## 📖 Inspiration

The chapter-based, notebook-driven presentation is inspired by resources such as Jake VanderPlas's *Python Data Science Handbook*. That work is organized around Jupyter notebooks and practical data-science workflows. This repository is an **independent educational project** with original structure, explanations, examples, and exercises.
