# 🐍 Python Handbook

> A structured, beginner-friendly Python learning handbook — from the fundamentals to practical development, data science, and machine learning.

**Python Handbook** is an open learning resource designed to help beginners learn Python step by step through clear explanations, practical examples, code breakdowns, exercises, and hands-on notebooks.

## 🧑‍💻 Learning Approach

Each topic follows a simple learning flow:

```text
Concept
   ↓
Simple Explanation
   ↓
Syntax
   ↓
Example
   ↓
Line-by-Line Explanation
   ↓
Practical Use Case
   ↓
Practice
   ↓
Challenge
```

The goal is not only to memorize Python syntax, but to understand **why the code works and how to use it in real projects**.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/renco88/python-handbook.git
```

Go to the project directory:

```bash
cd python-handbook
```

Because this is a static website, you can open `index.html` directly in a browser.

For a better development experience, you can also use a local development server such as VS Code Live Server.

---

## 🌍 Deploy with GitHub Pages

The project is ready to deploy as a static website.

### 1. Push your changes

```bash
git add .
git commit -m "Update Python handbook"
git push
```

### 2. Enable GitHub Pages

Go to:

```text
Repository
→ Settings
→ Pages
→ Deploy from a branch
→ main
→ / (root)
→ Save
```

Your website will then be available through GitHub Pages.
