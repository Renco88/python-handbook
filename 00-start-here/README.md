# 🚀 Start Here

Welcome to the Python Handbook.

## Who should start here?

Anyone who wants to learn Python systematically rather than jumping between random tutorials.

## How to study

For each chapter:

1. Read the README.
2. Open `lesson.ipynb`.
3. Run every cell.
4. Change the examples.
5. Try the practice tasks.
6. Solve the challenge without copying.
7. Build a small project.

## Recommended routine

**60–90 minutes per session**

- 15 min — concept
- 25 min — coding
- 20 min — experimentation
- 20 min — challenge
- 10 min — notes/review
