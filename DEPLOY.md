# Deploy

1. Upload all files in this folder to the root of `Renco88/python-handbook`.
2. GitHub → Settings → Pages.
3. Build and deployment → Source: Deploy from a branch.
4. Branch: `main`, folder: `/ (root)`.
5. Save.

Your site will be: https://renco88.github.io/python-handbook/

The site already contains direct Google Colab links for every chapter notebook.
